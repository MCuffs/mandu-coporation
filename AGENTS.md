# Project agent workflow

## User preference: keep work off screen

The user shares their screen with teammates. Do not launch, activate, raise, or foreground the Unity Editor or standalone player windows, including when work or a build finishes. Do not automatically enter Play Mode or open the Game view after a build.

Use file inspection, compilation, headless checks, existing saved captures, or background operations that do not activate windows. A request to resume development does not revoke this preference.
