# 다시, 한 방 v0.7.0 — Windows 플레이어블 데모

## 설치와 실행

SecondFist-v0.7.0-Windows-x64.zip을 내려받아 압축을 전부 풀고 SecondFist.exe를 실행하세요. Unity 설치는 필요하지 않습니다. Windows 64비트용입니다. 코드 서명은 적용하지 않았습니다.

## 이번 버전

- 시작 화면과 스테이지 선택, 시작 기술 선택
- 서로 다른 배경의 4개 스테이지: 학교 뒷골목, 네온 야시장, 노을 옥상, 항만 물류창고
- 복서, 긴 리치의 킥복서, 돌진하는 중량급, 정장 보스의 새 이미지와 피격 포즈
- 장소마다 달라지는 적 구성과 보스 외형
- 클리어하면 다음 장소 해금, 코인·기술·최고 기록·진행 저장
- 긴 프롤로그와 합성 내레이션 제외

## 조작

WASD / 방향키 / 마우스 드래그로 이동하고, 가까운 적은 자동 공격합니다. Space 또는 화면 오른쪽 아래 주먹 버튼으로 필살기를 사용하세요. Escape는 일시정지, F11은 전체 화면 전환입니다.

전투 중 기술 카드를 골라 벽꿍·충돌·기절을 강화할 수 있습니다. 첫 스테이지를 깨면 다음 스테이지가 열립니다. 결과 화면이나 일시정지 메뉴에서 시작 화면으로 돌아갈 수 있습니다.

## 범위

이 배포판은 플레이 테스트용 데모입니다. 광고·결제·온라인 순위·서버 저장은 연결하지 않았으며, 모바일 실기기는 검증하지 않았습니다. 저장은 이 PC의 로컬 프로필을 사용합니다. 폴더 안 Licenses에 글꼴 라이선스를 포함했습니다. SHA256SUMS.txt로 ZIP 무결성을 확인할 수 있습니다.
