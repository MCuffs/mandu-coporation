# 아빠 전쟁 — 디자인 개선 로드맵 v1

작성: 2026-11-04. 대상: codex/dad-war-design-v2. 이번 작업은 UI·아트·모션·효과·소리의 일관성 개선이다. 현재 전투·경제 규칙은 유지한다. 시스템 재기획은 [product v2](dad-war-product-v2.md), 확정 이야기·인물은 [dad-war-plan.md](dad-war-plan.md)를 참조한다.

## 1. 디자인 목표

피곤하고 진지한 아빠와, 과장된 충돌의 결과가 대비되는 생활 코미디다. 같은 얼굴·체격·외곽선·색 체계를 홈·전투·보상에서 유지한다. 새 화면은 실제 구현된 코인·도시락·강화·출발을 우선 배치한다. 미구현 상점이나 광고를 작동하는 기능처럼 표시하지 않는다.

현재 2D 빌드의 사용성을 먼저 개선한다. 유사 3D는 동일한 캐릭터·색·실루엣 기준으로 별도 검증한다. 이번에 만드는 배경·장식 PNG는 3D 모델이나 최종 3D 전투장이 아니다.

## 5. 화면별 개선 기준

### 홈

상단 코인·도시락 → 작은 제목·짧은 대사 → 아빠+사건 레이어 → 방치 보상 → 현재 스테이지·상대 → 출발 → 도시락/출발/강화. 아빠 얼굴에 알림 배지를 겹치지 않는다. 장면 속 성인 상대는 아빠보다 작게 두어 주인공이 명확해야 한다. 옛 도시락 배달 대사를 사용하지 않는다.

### 전투

체력·진행은 화면 상단, 기존 필살기는 손가락이 닿는 아래쪽이다. 기본 타격 글자는 작게, 벽꿍과 연쇄만 짧게 크게 강조한다. D3 시안에는 현재 미구현인 손 떼기 강타 게이지를 작동 UI로 그리지 않는다. 새 조작 시안은 별도로 표시한다.

### 성장·결과

기능명·실제 효과·비용을 분리한다. 개봉 카드에는 아이템, 등급, 현재/신규 차이, 장착/분해 순서로 배치한다. 결과는 기록보다 확정 보상과 다음 행동을 쉽게 찾게 한다. 광고 제안에는 시청 행동과 보상을 명시하며, 광고 SDK가 없는 시안은 미구현이라고 밝힌다.

## 6. 검수와 인계

- 자동 검수: 파일 존재·PNG 크기·알파, SVG 파싱, HTML 로컬 참조, manifest 일치.
- 시각 검수: 그림체·성인 외형·중앙 여백·배경/인물/문자 분리·효과 셀 경계.
- Unity 적용 후: 실제 폰트 선명도, 안전 영역, 클릭 영역, 모달 상태, 화면비 9:16·9:19.5와 PC 비교.
- 사람 테스트: 홈에서 다음 행동 찾기, 전투 중 공격 예고 읽기, 장비 비교 이해, 다음 판 진입.
- 상태 구분: 원화 생성 → 검수 → 시안 사용 → Unity 임포트 → 런타임 연결 → 실기기 통과.

이번 납품은 로드맵, 첫 묶음 에셋, 공통 UI 기준, 정적 미리보기까지다. 전체 게임 UI 적용과 3D 전환 완료를 의미하지 않는다.
