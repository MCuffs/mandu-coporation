# 프롤로그·전체 화면 v4

## 화면
회색 인위적 경계선을 제거했습니다. 상하 고정 패널을 없애고 전투 배경이 화면 전체를 채웁니다.
작은 체력/레벨/구역/시간 표시와 필살기 버튼만 전투 위에 표시합니다.
가로·세로 화면에 따라 전투 영역과 UI 위치가 바뀝니다. 기본 전체 화면, F11 창 모드 전환.

## 프롤로그
1. 팔룡회 전국구 보스 정민수, 조직의 배신.
2. 죽음은 힘이 풀리는 손과 반지, 암전으로 암시.
3. 섬광 뒤, 일진에게 폭행당하는 아들의 몸에서 깨어남.
4. “야 가서 니네 부모 모셔와.”
5. 엄마의 등장과 위협, 절규.
6. 아들의 울부짖음과 아버지의 죄책감이 분노로 이어짐.
7. “니들 다 뒤졌다.” / “내가 누군지 아냐!” / “나 팔룡회 정민수다!”
8. 같은 골목으로 전환되며 첫 전투 시작.

## 그림과 컷 연결
사용자가 제공한 참고 이미지에서 거친 펜선, 해칭, 얼굴의 강한 검은 그림자, 절제된 회색과 암적색을 참고했습니다.
인물과 구도는 새로 구성했습니다. 사용자 참고 원본 이미지는 저장소에 포함하지 않습니다.
손의 매치 컷, 엄마와 아들의 시선 연결, 와이드에서 얼굴 클로즈업으로 전환, 침묵·암전·섬광으로 흐름을 구성합니다.
같은 원화에서 대사만 바뀔 때는 카메라를 처음으로 되돌리거나 암전을 반복하지 않습니다.

최종 원화: Assets/Alley/Resources/PrologueInkScenes.png
도구: 내장 image_gen.
생성 프롬프트: Design/prologue-v4-prompt.txt
첫 컬러 시안은 최종 빌드에서 사용하지 않습니다.

## 음성
Assets/Alley/Resources/Voice/Prologue/00, 02, 03, 05, 10, 11, 12, 13.mp3
정민수 독백과 핵심 대사 8줄의 임시 합성 음성입니다. 엄마와 아들의 절규는 대사·원화·효과음으로 표현합니다.
음성이 긴 컷은 클립 길이 이상 유지하고, 컷을 넘기거나 건너뛰면 이전 음성을 멈춥니다.
음성 생성 도구: edge-tts, Microsoft ko-KR-HyunsuMultilingualNeural, rate -12%/-8%, pitch -8Hz.
재생성 스크립트: Tools/generate_prologue_voice.py (Tools/requirements-voice.txt 참고).
도구 문서: https://github.com/rany2/edge-tts
실제 성우 녹음으로 교체할 수 있도록 컷별 AudioClip을 분리했습니다.
