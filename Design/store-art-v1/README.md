# 아빠 전쟁 스토어 그림
Play Console 기본 스토어 등록정보의 앱 아이콘에 store_icon_512.png, 그래픽 이미지에 store_feature_1024x500.png를 사용한다. 후자는 실제 게임 타이틀 원화에 프로젝트의 Black Han Sans 제목을 얹은 홍보 이미지다. 플레이 스크린샷은 기존 실황 캡처를 사용한다.
store_icon_fg와 store_icon_bg는 차기 Android 빌드의 적응형 아이콘 레이어다. logo_title_ko와 store_shot_frame은 선택적으로 사용한다.
아이콘은 내장 이미지 생성기로 dad_ready를 참고해 제작했다. 지시문은 칠석의 반쯤 감긴 눈, 큰 코, 올리브색 조끼를 유지하고 볼 옆에 흰 골프공을 든 상반신을 굵은 먹선으로 그리는 것이다.
