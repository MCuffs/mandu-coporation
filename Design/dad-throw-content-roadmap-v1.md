# 아빠 전쟁 — 가로 투척 콘텐츠·스테이지 구성 v1

2026-11-17. 사용자 승인: 넓은 구도 v2를 시각 기준으로 채택. 아래 콘텐츠·배치·수치·해금 순서는 **추가 제안**이며 구현/흥행/난이도 검증 완료를 뜻하지 않는다. 새 코드·이미지·APK를 제작하는 문서가 아니다.

## 1. 콘텐츠의 중심

**‘무엇을 더 강하게 던지나’보다 ‘어떻게 모아서 한 번에 맞히나’를 먼저 확장한다.**

전투의 새로움은 다음 순서로 만든다.

1. 같은 적이라도 간격·무리 크기·등장 시차를 바꾼다.
2. 신발의 밀치기를 공격/시간 벌기/무리 합치기에 다르게 사용한다.
3. 빠른 상대와 무거운 상대를 한 종류씩 추가한다.
4. 기본 두 물건으로 설명하기 어려운 상황이 확인된 뒤 골프채를 추가한다.
5. 낚싯대·자동차는 별도 관문을 통과한 후 확장한다.

배경만 바꾸거나 체력만 올린 스테이지를 다량 생산하지 않는다. 장비 부위·등급·뽑기·일일 숙제·별 과제는 다시 늘리지 않는다.

## 2. 화면과 진행

[넓은 구도 v2](dad-throw-screens-v2/index.html)를 이후 아트/레이아웃의 기준으로 사용한다. 화면상 인물 크기와 전투 판정/실제 경기장 폭을 혼동하지 않는다. 모델 좌표 변경은 별도 코드 검증 대상이다.

`시작/계속 → 스테이지 전투 → 완료(코인/강화/다음) → 다음 스테이지`

스테이지 지도는 첫 범위에서 만들지 않는다. `1-3`처럼 짧은 번호로 구분하고 ‘다음’으로 이어간다. 처음 두 판은 한 웨이브, 이후 한 스테이지2~3개 무리의 연속 진입을 제안한다. 무리 사이에 별도 결과 창을 띄우지 않고 스테이지 끝에서만 정산한다. 기존 시제품의 무한 증가형 Wave와 아래의 수제 스테이지는 아직 연결하지 않았다.

첫 사람 테스트용 콘텐츠는 **1장5판만** 만든다. 2·3장은 방향과 제작비 비교용 후보다. 첫5판의 총 플레이 목표는5~8분 이내이며 현재 실측값은 아니다.

## 3. 1장 — 우리 집 앞: 모아서 맞히기

배경은 현재 v2 주택가 하나를 사용한다. 새로운 상대·무기 없이 배치로 변화를 만든다. 골프공과 신발은 처음부터 선택 가능하게 두되 화면 설명을 늘리지 않는다.

| 판 | 이름(기획용) | 배치 제안 | 플레이어가 바꿀 행동 | 새 자산/코드 |
|---|---|---|---|---|
| 1-1 | 한 발이면 된다 | 가까운1명 뒤로3명이 차례로 접근, 총4명 | 당겨 놓고 맞히는 방향 이해 | 기존 적/물건, 가까운 첫 등장 위치 |
| 1-2 | 줄 서세요 | 짧은 간격4명씩 두 무리, 총8명 | 낮은 탄도로 한 줄 관통 | 등장 간격·묶음 데이터 |
| 1-3 | 뒤로 좀 가세요 | 선두2명과 늦게 따라오는4명×2, 총12명 | 선두를 신발로 밀어 후속과 합치기 | 신발 사용 시점 검증. 설명은 최초 손가락/아이콘 정도 |
| 1-4 | 먼저 막을까, 모을까 | 작은 가까운 무리와 큰 먼 무리, 총16명 | 눈앞 위협 처리와 큰 관통 기회의 선택 | 서로 다른 등장 시차 |
| 1-5 | 동네 한 바퀴 | 배운 패턴3개를 섞어 총20~24명 | 무기 전환과 재장전 시점 활용 | 새 보스 없이 학습 종합 |

수치는 목표 배치를 설명하기 위한 초기안이다. ‘신발을 써야만 통과’하게 막지 않는다. 골프공만 잘 쏴 통과하는 숙련도는 허용하되, 신발을 쓰면 더 안전하거나 더 큰 관통이 가능해야 한다.

1-1에서 관통보다 단일 적을 연속 클릭하는 것으로 오해하면 조준선·첫 배치를 수정한다. 1-3에서 신발 사용 뒤 실제 간격이 줄어들지 않으면 적 종류/아이템을 추가하기 전에 밀치기 범위·감속·후속 진입 속도를 수정한다.

## 4. 2장 후보 — 골목 입구: 서로 다른 속도

**조건:** 1장에서 ‘모으고 관통한다’가 사람 관찰로 확인된 뒤 제작한다. 주택가 배경의 저채도 골목 변형1장만 추가하며, 장애물·고저차·새 조작은 넣지 않는다.

| 판 | 변주 | 핵심 판단 |
|---|---|---|
| 2-1 | 빠른 상대1명 + 일반 무리 | 먼저 앞질러 온 상대를 밀어 같은 줄로 모으기 |
| 2-2 | 작은 빠른 무리와 큰 느린 무리 | 효율 좋은 큰 무리를 기다릴지 집 앞을 지킬지 |
| 2-3 | 빠른 상대를 일반 무리 뒤에 배치 | 스스로 뭉칠 때까지 기다리는 발사 시점 |
| 2-4 | 같은 총인원, 두 가지 진입 간격 | 상황에 따라 신발 사용 시점을 바꾸기 |
| 2-5 | 큰아빠1명 + 일반 상대 | 큰아빠에게 연속 타격을 집중할지 먼저 주변을 정리할지 |

이 장에서 추가할 상대는 최대2종이다. 방패·점프·원거리 공격·회피를 동시에 도입하지 않는다. 새 역할 소개는 첫 등장에만 짧게, 이후에는 실루엣과 움직임으로 읽히게 한다.

## 5. 3장 후보 — 동네 공터: 많은 적과 큰 물건

**조건:** 2장과 추가 물건의 제작/검증 여유가 있을 때만 진행한다. 한 번에 보이는 수를 계속 늘리기보다 시간차로 많은 적이 들어오게 한다.

| 판 | 변주 | 검증할 변화 |
|---|---|---|
| 3-1 | 일반 상대의 큰 무리 | 정확한 낮은 관통이 많이 맞는 보상 |
| 3-2 | 빠른 소수→느린 다수 | 신발로 시간을 확보하고 다음 발사를 준비 |
| 3-3 | 큰아빠 뒤의 일반 무리 | 앞의 높은 체력에 막힐 때 다른 물건을 고르는가 |
| 3-4 | 쉬운 무리 사이 짧은 압박 구간 | 휴식과 위기를 구분해 재사용 대기 관리 |
| 3-5 | 기존 조합의 최종 혼합 | 새로운 규칙 없이 배운 대응을 종합 |

골프채를 이 장의 후보 물건으로 삼는다. 최초 획득 경로는 코인 구매와 짧은 무료 체험 중 선택하되, 미구매 상태에서도 기본 물건으로 통과할 수 있게 설계한다. 물건 가격·정확한 해금 판은 아직 정하지 않는다.

총적 수30~60명, 동시에 읽어야 하는 적12~24명 범위를 초기 튜닝안으로 제안한다. **현재 모델의 활성80/총84 상한은 기술적 폭증 방지값**이며 가독성·성능이 검증된 콘텐츠 목표가 아니다. 대량 등장에서도 FPS·판정·그림 겹침이 나쁘면 더 늘리지 않는다.

## 6. 상대 역할 — 초기에는 세 가지

| 상대 | 겉모습 단서 | 행동 초안 | 신발/골프공과의 관계 |
|---|---|---|---|
| 일반 아저씨 | 현재 캐릭터 | 일정한 보행·낮은 체력 | 모여 있을수록 관통의 이득 |
| 성급한 아저씨 | 운동복, 큰 보폭 | 일반의약1.35배 속도, 체력은 동일 | 신발로 늦추면 후속 무리와 만나기 쉬움 |
| 큰아빠 | 넓은 몸, 느린 걸음 | 일반의약0.75배 속도, 초기 체력2~3 제안 | 신발 밀림을 줄이되 면역은 아님. 주변을 정리한 뒤 재타격 |

속도/체력/밀치기 저항은 미검증 수치다. 역할마다 색만 바꾸지 않고 체형·걸음으로 구분한다. 명칭·수치는 기획용이며 모든 적 머리 위에 이름표를 띄우지 않는다. 초반 보스 전용 체력 단계·소환·분노 패턴은 넣지 않는다.

## 7. 물건 확장 순서

| 순서 | 물건 | 추가되는 판단 | 제작·도입 조건 |
|---|---|---|---|
| 현재 | 골프공 | 각도·발사 시점·관통 | 기본 탄도와 시각 피드백부터 검수 |
| 현재 | 신발 | 밀치기·감속·합류 | 골프공과의 차이가 사람에게 보이는지 확인 |
| 다음 후보 | 골프채 | 긴 회전 판정으로 앞의 여러 상대 처리 | 골프공보다 무조건 강하지 않게 긴 재사용 대기/짧은 유효 거리 비교 |
| 후속 비교 | 낚싯대 | 한 상대를 끌어 무리 위치를 바꿈 | 줄/훅/복귀 표시의 가독성·제작비를 별도 검증. 골프채와 동시 제작하지 않음 |
| 장기 보상 | 자동차 | 큰 위기를 정리하는 제한 사용 물건 | 횟수제한1회/스테이지를 초기 제안. 전체 화면 가림과 성능 검수 필요 |

기본 선택2개+특수1개 이내를 유지한다. 물건이 늘면 세로 상점 탭을 추가하지 말고 완료 화면에서 작은 선택 목록으로 교체한다. 아직 선택/해금/가격/사용 제한 시스템은 구현하지 않았다.

## 8. 보상과 재도전

- 스테이지 완료 코인과 다음 판 진입이 기본 보상이다. 장마다 추가 물건이나 간단한 장소 변화가 다음 목표가 된다.
- 처음에는 강화 하나를 유지한다. 물건마다 여러 능력치·희귀도·강화 트리를 추가하지 않는다.
- 실패하면 같은 배치로 재시작해 조준과 신발 타이밍을 바꿔볼 수 있게 한다. 실패 직후 임의로 적 수나 체력을 바꾸지 않는다.
- 장기 코인·해금은 본제작에서 저장/복구를 검증한 뒤 연결한다. 현재 시제품은 세션 재시작 시 초기화된다.
- 별3개·일일 미션·광고 시청 과제를 초반 콘텐츠 소진 방지책으로 다시 붙이지 않는다.

## 9. 제작 순서와 범위 제한

1. **가로 화면 적용·기기 확인:** v2 구도와 투사체/손 앵커, 배경 바닥·실패 경계, 터치·회전·정지 확인. 현재 화면 시안은 Unity 미적용이다.
2. **1장5판 데이터와 배치:** 기존 물건/상대만으로 구현. 가장 먼저1-1/1-3을 만들어 단일 타격과 모으기를 비교한다.
3. **사람 관찰:** 처음 하는5~8명에게 첫 발사·관통 이해·자발적 신발 사용·추가 판 여부를 관찰한다. 기존 전략의8명 기준을 참고하되 작은 표본으로 유지율을 선언하지 않는다.
4. **필요할 때만 적1종 추가:** 빠른 상대를 먼저 비교하고, 배치만으로 충분하면 추가 원화를 줄인다.
5. **골프채 또는 2장 확장:** 기본 재미·성능·제작 상한을 보고 둘 중 하나씩 투자한다.
6. **낚싯대/자동차/3장:** 별도 승인 이후다. 이 문서가15판 전체 제작을 승인하는 것은 아니다.

## 10. 채택·보완 판단

**지지 신호:** 플레이어가 선두/후속의 간격을 보고 신발을 선택하고, 그 뒤 골프공으로 여러 명을 맞혔다는 인과를 설명한다. 같은 판 재도전에서 발사 시점이 달라진다.

**실패 신호:** 무조건 골프공 난사가 최선, 신발이 오히려 맞히기 어렵게만 함, 이미 모든 적이 겹쳐 있어 모으기가 필요 없음, 어떤 적이 집에 닿았는지 알 수 없음, 여러 물건 버튼 때문에 조준을 놓침.

실패 시 새 배경·신종·강한 아이템을 더하지 않는다. 간격→신발 범위/감속→발사 속도/관통 한도 순서로 한 요소씩 조정한다. 재미 가설은 구현량이나 검사 통과로 증명되지 않는다.
