# 슬링샷 성장·재도전 보완 v1

2026-11-05. `224abcf` 이후 로컬 구현. 수치는 첫 적용값이며 사람의 체감·밸런스 검증 전이다.

## 변경

- 강화 상한을 UI와 구매 함수 양쪽에서 검사한다. 최대 항목은 구매할 수 없고 코인/공유 비용도 변하지 않는다.
- 들이받기는 직접 충돌 피해 보너스로 변경했다(레벨당 3%, 최대 60%). 정수 피해에서 작은 보너스가 사라지지 않도록 판 내 직접 명중 사이에 소수 피해를 누적하고 1 이상일 때 추가한다. 무작위 치명타가 아니다. 전달력과 비거리를 같은 값에 곱하던 중복을 제거했다.
- 도움닫기/체력/멀리 날리기의 기존 수치와 Lv.10 벽 피해는 유지한다.
- 도시락 장비를 아래 패시브로 연결하고 전투력 대신 실제 효과를 카드와 장착 알림에 표시한다. 슬롯을 누르면 현재 효과를 확인할 수 있다.
- 신규 획득의 첫 장비는 희귀 손 장비, 두 번째는 신발이다. 이후 빈 부위부터 채운다. 기존 장비/진행/등급/미결정 카드를 지우지 않는다.
- 승리 결과에 `같은 판 다시`, 홈 출발 탭에 `지난 판 · 별 도전`을 추가했다. 목록에는 해금한 판만 표시하고 별과 최소 성공 발사 수를 보여준다.
- 승리한 발사 기록만 갱신하며 더 나쁜 기록은 덮지 않는다. 재도전 승패가 원래 진행 목적지를 뒤로 이동시키지 않는다. 기존 최초 보상/재플레이 보상 규칙은 유지한다.

## 장비 매핑

기존 저장의 `gearValue`는 품질 값으로 보존한다. 각 부위의 효과는 `상한 × 품질/(품질+0.01)`이다. 같은 부위에서는 품질이 높을수록 효과가 좋으므로 기존 자동 비교/모두 열기 순서가 일관된다. 별도 액티브 스킬이나 다중 능력 선택은 이번에 추가하지 않았다.

| 부위 | 효과 | 추가 효과 상한 |
|---|---|---|
| 신발 | 벽 튕김 속도 보존 | +10%p, 기본 88%와 합쳐 98% 미만 |
| 손 | 맞은 상대에게 전달되는 충격 속도 | +50% 미만 |
| 상의 | 최대 체력 | +40% 미만 |
| 머리 | 조준 중 진행 속도를 더 늦춤 | 0.5배에서 최대 0.15 감소 |
| 소지품 | 피격 뒤 보호 시간 | 기본 0.6초에 최대 0.3초 추가 |
| 생활용품 | 맞은 상대 비거리(속도 배율) | +40% 미만 |

특수 발사 3종과는 별도로 곱/합산한다. 예측선은 기존처럼 첫 벽 튕김 이후 짧은 구간을 보여주며 실제 적 충돌은 예측하지 않는다.

## 저장 호환

`bestShots` 배열(0은 기록 없음)을 추가했다. 기존 v2 저장에 없으면 빈 배열로 보완한다. 기존 quality 값은 변환/삭제 없이 사용한다. 이전에 최대 레벨을 초과해 산 강화는 레벨 자체를 지우지 않고 효과 상한만 적용하며 추가 구매를 막는다. 이미 쓴 코인의 자동 환불은 하지 않는다.

## 검증

- 설치된 Unity 2021.3.2f1의 Mono 컴파일러와 Unity DLL을 사용해 전체 런타임 소스와 에디터 소스를 컴파일했다. 오류 없음. 기존 Alley 코드의 미사용 필드 경고 3개가 남는다.
- Unity DLL을 참조한 독립 Mono 실행: 신규 핵심 회귀 검사 20개 + 기존 슬링샷 규칙 검사 34개 통과. `dad-growth-replay-headless-checks.txt`.
- 신규 검사: 상한/잘못된 구매 거절, 6부위 효과, 같은 벽 발사의 신발 전후 속도, 품질 비교의 단조성, 재도전 진행 유지, 성공 최소 발사 기록, 작은 직접 피해 누적.
- 에디터 배치용 회귀 검사는 `DadGrowthChecks.Batch`. 저장 재로드/기존 v2 JSON 로드 및 기존 에셋·경제 검사도 포함하지만 **이번 환경에서는 실행되지 않았다**.
- Unity 배치 시작이 라이선스 인증 오류(`Failed to activate/update license`)로 실패했다. 따라서 Unity Play Mode, GUI/ScrollView 터치, 실제 JsonUtility 저장 재로드는 미검증이다.
- 설치된 에디터의 PlaybackEngines에는 WindowsStandaloneSupport만 있다. Android 모듈 부재로 APK/AAB는 제작하지 못했다. 실기기 검수도 하지 않았다.

Unity 실행이 가능한 환경에서 실행할 검사:

```sh
Unity -batchmode -nographics -projectPath <repo> -executeMethod DadGrowthChecks.Batch -logFile <log>
```
