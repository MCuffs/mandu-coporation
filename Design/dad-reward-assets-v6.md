# 보상·벽꿍 추가 에셋 v6

## 범위

도시락 개봉 3단계, 장비 카드 배경 3종, 사물함 파손 흔적 3단계. 기존 v5 에셋을 대체하지 않는 추가 묶음이다.

생성: 내장 image_gen. 전체 프롬프트는 `dad-reward-assets-v6-prompts.json`에 보관한다. 원본 PNG는 `Assets/DadSchoolBoss/Art/V6Rewards/`에 둔다. 이 묶음은 에셋 납품이며, 게임의 보상 로직·장비 시스템 연결은 별도 작업이다.

## 사용 규칙

| 파일 | 용도 |
|---|---|
| lunchbox_closed.png | 개봉 시작, 닫힌 도시락 |
| lunchbox_opening.png | 뚜껑이 들리는 중간 포즈 |
| lunchbox_open.png | 개봉 완료, 장비 아이콘을 별도 표시 |
| gear_card_common.png | 일반 장비, 회색 테두리 |
| gear_card_rare.png | 희귀 장비, 파란 테두리 |
| gear_card_best.png | 최고 등급 장비, 노란 테두리 |
| locker_damage_1.png | 약한 찌그러짐 |
| locker_damage_2.png | 깊은 찌그러짐 |
| locker_damage_3.png | 찢어진 금속·구멍 |

- 도시락은 연속 손그림 포즈다. 구현 시 바닥 기준을 맞추고, 중간 포즈 전후에 약한 축소·확대를 섞는다. 정밀한 프레임 애니메이션으로 간주하지 않는다.
- 카드의 빈 공간에 기존 v5 장비 아이콘과 실제 수치를 Unity UI로 배치한다. 글자와 수치를 이미지에 굽지 않는다. 등급은 색과 테두리 모양을 함께 사용한다.
- 사물함 파손은 배경 위에 올리는 투명 데칼이다. 동일 위치의 단계를 교체하고 좌우 반전해 반복을 줄인다. 배경의 사물함 폭에 맞춰 크기를 조정한다.
- 반짝임·흔들림·화면 정지·보상 숫자는 Unity에서 처리한다.
- 외곽 투명 여백이 있으므로 레이아웃은 캔버스 전체가 아닌 실제 그림 영역을 기준으로 조정한다. 카드에는 9-slice 규격을 부여하지 않았으므로 원래 비율을 유지한다.
- 일부 카드·파손 흔적에는 반투명 외곽 음영이 남아 있다. 밝은 배경 위 합성 미리보기로 확인하고, 강하면 데칼 머티리얼의 알파 임계값으로 줄인다. 원본 알파는 보존했다.
- 3단계 파손의 중앙은 투명 영역이다. 깊은 구멍처럼 보이게 하려면 아래에 작은 짙은색 면을 별도로 배치한다.

## Unity 임포트 권장값

UI는 Sprite (2D and UI) / Single, Alpha Is Transparency 켜기, Mipmap 끄기, Wrap Clamp, Bilinear. 도시락은 최대 1024, 카드·데칼은 최대 512부터 확인한다. 현재 폴더는 원본 보관 위치이므로 기존 DadArt 로더에서 자동 표시되지 않는다. 연결 시 런타임에서 쓰는 항목만 Resources 또는 참조 필드로 옮긴다.

## 검수 결과

9개 PNG 모두 RGBA 및 투명 픽셀 확인. 그림을 개별 확인했으며, 카드 중앙의 잘못된 투명 구멍과 닫힌 도시락의 층수 불일치를 수정했다. 파일별 크기·실제 그림 영역·SHA-256은 원본 폴더의 `manifest.json`에 기록했다. 게임 내 합성과 Android 실기기 검수는 아직 수행하지 않았다.

## 연결 순서

1. 결과창의 도시락 보상을 누르면 개봉 3포즈를 약 0.5초 동안 재생한다.
2. 장비 카드 하나를 표시하고 기존 장비와 비교·장착하도록 한다.
3. 벽꿍 발생 위치에 파손 흔적을 배치한다. 전투당 위치별 최대 3단계로 제한한다.

에셋만으로 장비 뽑기나 성장 재미가 완성되는 것은 아니다. 실제 아이템 효과와 보상 정산을 연결한 뒤 첫 이용자의 이해도와 재도전을 확인한다.
