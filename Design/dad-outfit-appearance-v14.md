# 장착 장비 외형 v14

> 과거 구현 기록. 외형 결함과 상의 재색칠 방식은 [V17 수정](dad-equipment-appearance-v17.md)으로 대체했다.

2026-11-06. 장비 효과만 바뀌던 상태에서, 실제 장착 슬롯을 캐릭터 외형에 연결했다. 새 투명 착용 부품은 내장 image_gen으로 제작했고, 정확한 프롬프트·참조·출처는 원본 폴더 `generation.json`에 보관한다.

## 연결

| 부위 | 외형 |
|---|---|
| 신발 | 고무 슬리퍼 / 삼선 슬리퍼 / 등산화. 원래 신발의 검정·흰 부분은 가려 이중으로 신지 않게 처리 |
| 손 | 목장갑 / 빨간 고무장갑 / 권투장갑. 편 손과 쥔 주먹의 별도 부품 사용 |
| 상의 | 기본 초록 조끼 / 크림색 / 갈색. 기존 의복 실루엣의 색상 변형이며 런닝셔츠·낚시 조끼의 별도 재단 실루엣을 새로 만든 것은 아님 |
| 머리 | 돋보기 안경 / 선글라스 / 등산 모자를 눈·머리 위치에 부착 |
| 소지품 | 폴더폰 / 리모컨 / 신문지를 한 손에 표시 |
| 생활용품 | 효자손 / 장우산 / 골프채를 다른 손에 표시 |

완성 세트로 교체하지 않는다. 슬롯마다 현재 장착 등급의 아이템을 독립적으로 선택하며 서로 섞어 쓸 수 있다. 보유·미보유·장착 데이터 및 전투 효과는 바꾸지 않았다. 첫 번째 상의는 원래 초록 조끼 외형을 재사용한다.

## 적용 위치

- 홈, 도시락 탭의 아빠, 결과의 아빠.
- 메인 슬링샷의 대기·조준·비행 2종·벽 튕김·착지·피격.
- 기준 포즈 8개: idle 0/1, pull, flight 0/1, bounce, land, hurt.
- 같은 변환 안에서 본체와 장비를 그려 좌우 반전/회전/크기 변경을 함께 따른다.
- 보관용 옛 자동 펀치 포즈에는 추측한 위치로 부품을 붙이지 않는다. 오프닝/타이틀은 사전 제작 일러스트이므로 장비와 연동하지 않는다.

## 에셋

- 원본: `Assets/DadSchoolBoss/Art/V14Outfits/wear_parts.png` (1254×1254 RGBA, 투명)
- 런타임: `Assets/DadSchoolBoss/Resources/DadV14/wear_parts.png`
- 3×3 atlas의 위 행은 편 장갑 3종, 중간은 쥔 주먹 3종, 아래는 신발 3종.
- `wear_uv.json`은 각 셀의 실제 alpha 경계를 읽어 만든 UV 데이터다. 원본 PNG를 잘라 재저장하지 않는다.
- 안경/모자/손 소품은 기존 `DadV5/gear` PNG를 재사용한다.

## 구현

`DadOutfitRenderer`가 같은 768 기준 캔버스에서 착용 위치와 부품을 관리한다. `DadSchoolJuice.DrawCharacter`, 슬링샷의 `DrawCharacter/DrawPose`가 이를 호출한다. 슬링샷은 호스트의 현재 진행 데이터를 받아 장착 상태를 공유한다.

상의 색상과 기존 신발 가림은 런타임 384×384 캐시에 처리한다. 원본은 수정하지 않고 피부·바지·검은 의복 외곽선은 색상 변경에서 제외한다. 같은 포즈는 캐시를 재사용하고 상의/신발 착용 상태 변경이나 객체 해제 시 캐시를 정리한다. GPU→CPU 읽기는 처음 필요한 포즈에서만 발생하므로 저사양 Android에서 첫 표시 지연/메모리는 추가 측정해야 한다.

슬롯 수치가 변해도 같은 외형이면 캐시를 다시 만들지 않는다. 비주얼 크기와 무기는 충돌 반경/피격 범위를 바꾸지 않는다.

## 검수

- 전체 런타임/에디터 코드 컴파일.
- Unity 외형/캐시/저장 재로드 검사 11개 통과 (`dad-outfit-checks-v14.txt`).
- 기존 Play Mode 연결 검사 50개, 경제/에셋 보고서 73개 통과.
- 미장착, 일반/희귀/최고 장착 예시, 혼합 장착, 전투 대기/조준/비행을 실제 Unity에서 촬영했다. 원래 진행 데이터는 임시 감사 후 복원했다.
- 등산화 아래 기존 슬리퍼가 겹치는 현상과 팔 위에 주머니가 보이는 현상을 검수해 수정했다. 주머니 덧그림은 제외했다.
- 실제 화면: [외형 비교](dad-outfit-preview-v14.html), [감사 캡처](dad-outfit-ui-v14/).
- 아트 파츠 연결은 완료했지만 Android 실기기의 터치/메모리/성능은 미검증이다. 상의의 별도 실루엣은 현 단계 범위에 포함하지 않았다.

재현: Unity 메뉴 `Dad School Boss/Run Outfit Checks`, 브리지 명령 `outfitchecks`, 화면 감사 `outfitui:<폴더>`.
