# 오늘의 도전조 v1 — 가로 던지기

2026-11-18. [30일 콘텐츠 기획 v1](dad-throw-content-plan-30d-v1.md)을 사용자가 "이대로 진행"으로 승인한 뒤 만든 첫 조각이다. 기획 5절의 「오늘의 도전조」를 지금 있는 그림만으로 넣었다. 새 그림은 쓰지 않았다([에셋 요청서 v4](dad-throw-asset-request-v4.md)의 4D·4K가 오면 바꿔 끼운다).

**상태: 규칙과 화면 코드가 들어갔고 창 없는 검사를 통과했다. 같은 날 Unity 2021.3.2f1 에디터에서 컴파일 오류 0, 화면 11장을 찍어 확인했다(아래 "Unity 화면 확인"). 사람이 해 본 기록과 실기기 확인은 없다.**

## 무엇이 생겼나

| 무엇 | 내용 |
| --- | --- |
| 언제 열리나 | 처음 게임을 한 날의 **다음 날부터**, 깬 판이 하나라도 있으면. 이 기능이 생기기 전부터 깬 판이 있던 저장은 기다리지 않고 바로 열린다 |
| 어디서 여나 | 타이틀 왼쪽 아래의 「오늘의 도전조」 버튼. 열리기 전에는 버튼이 없다. 기회가 남아 있으면 빨간 점이 붙는다(집 앞 화면이 생기면 우편함으로 옮긴다) |
| 오늘의 판 | 이미 깬 판 가운데 대장이 없는 판, 그중 최근 여섯 판에서 하나 |
| 규칙 카드 | 열두 장 가운데 한두 장. 맨 첫 도전장은 한 장 |
| 기회 | 하루 세 번. 시작하는 순간 한 번이 쓰인다(지고 있을 때 나가도 돌려주지 않는다) |
| 보상 | 돌려보낸 사람 한 명당 1원은 그대로. 그 위에 하루 한 번씩: 깨기 100원, 대문을 한 번 이하로 내주고 깨기 100원, 한 공에 15명 맞히고 깨기 150원 |
| 날짜 | 기기 시계. 하루 내내 같은 도전장이고, 그날 판을 더 깨도 바뀌지 않는다. 서버는 없다 |
| 본편과의 관계 | 도전조를 깨도 다음 판이 열리지 않는다. 난이도 조절(지면 쉬워지고 연달아 깨면 어려워지는 것)에도 세지 않는다. 상점에서 산 것은 그대로 쓴다 |

숫자(기회 3번, 보상 100·100·150원, 한 공에 15명)는 처음 잡은 값이다. 사람이 해 본 적이 없다.

## 규칙 카드 열두 장

| 카드 | 하는 일 | 구현 |
| --- | --- | --- |
| 피구 대회 | 모두가 피구 아저씨 속도로 온다 | 판의 표 |
| 쟁반 행렬 | 보통 무리마다 앞줄 네 명이 쟁반을 든다(인원은 그대로) | 판의 표 |
| 공만 | 신발을 못 쓴다. 공은 절반 시간에 다시 던진다. 쟁반은 내려놓고 온다 | 표 + 던지기 |
| 신발 잔치 | 신발을 0.15초마다 던진다. 공은 세 배 느리다 | 던지기 |
| 큰 손 | 공이 두 배 크고 절반만 뚫는다 | 던지기 + 화면 |
| 통통 | 공이 세 번 튄다 | 던지기 |
| 단판 승부 | 대문을 한 번 내주면 끝난다 | 판의 표 |
| 거꾸로 | 단단한 상대가 처음부터 길에 서 있다 | 판의 표 |
| 돈벼락 | 한 판 상한(160명)까지 오고 한 명당 2원 | 표 + 돈 |
| 안개 | 길 오른쪽 절반이 뿌옇다 | 화면만 |
| 외길 | 공이 끝까지 뚫는다. 쌍둥이 공은 쉰다 | 던지기 |
| 대장 난입 | 이긴 대장이 판 중간에 걸어 들어온다(체력 20) | 판의 표 |

- **판에 맞는 카드만 나온다.** 거꾸로는 단단한 상대가 있는 판(1-3부터), 대장 난입은 1-5를 깬 뒤에만.
- **같이 나오지 않는 짝:** 공만 + 쟁반 행렬, 공만 + 신발 잔치, 공만 + 대장 난입(쟁반과 웅크린 대장은 신발이 있어야 한다), 단판 승부 + 대장 난입(대장은 대문을 짚고 다시 오므로 그것만으로 끝난다), 큰 손 + 외길.

같이 넣은 것(에디터 전용):

- 원격 명령 `dailyaudit:<폴더>`가 위 11장을 찍는다. 메모리 안의 플레이어로만 돈다.
- **원격으로 켠 플레이는 저장 파일을 쓰지 않는다.** 도전장이 생긴 뒤로는 타이틀에 서기만 해도 저장을 쓰기 때문이다. `play`가 에디터 세션에 표시를 남기고 `stop`이 지운다. `real` 명령은 표시를 지우고 플레이어의 저장으로 돌아가 다시 쓴다.
- 캡처를 찍는 동안 플레이어의 저장 파일은 바뀌지 않았다(찍기 전후 해시가 같다).

## 확인하지 못한 것

- 1280×720과 길쭉한 폰 화면, Android 실기기에서는 보지 않았다.
- 규칙 카드 아이콘·봉투·기회 표시·상자 그림은 아직 연결하지 않았다. 도전장의 카드 아래쪽이 비어 보인다(그림이 들어갈 자리다).
- 사람이 해 보지 않았다. 카드가 재미있는지, 세 번이 맞는지, 보상이 다음 날 켤 이유가 되는지 모른다.
- 대장 난입의 대장은 1장 대장 한 명뿐이다(지금 대장이 그것뿐이다).
- 같은 작업 폴더에 다른 세션이 올리지 않은 변경(스포츠카, 의자 아저씨 수정)이 `DadThrowModel.cs`·`DadThrowGrowth.cs`·`DadThrowPrototype.cs`·`chapter1.json`에 있다. 그 변경은 건드리지 않았고, 490개 검사는 그 변경이 들어 있는 상태에서 통과한 것이다.
