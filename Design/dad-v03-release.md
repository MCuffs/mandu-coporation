# 아빠 전쟁 v0.3.0 — Windows 플레이테스트

2026-11-10. Google Play 출시판이 아닌 Windows64 Development 테스트 배포다. 기존2021 엔진 사본에서 빌드했고, 별도 Unity6/Android 전환은 설치 권한 문제로 대기 중이다.

## 바뀐 플레이

- 타이틀의 ‘대소동 바로 시작’으로 스토리 없이 곧바로 한 판. 이야기와 본편은 별도 버튼으로 유지한다.
- 수제 도전8→12판: 카트 도미노, 매트 양갈래, 움직이는 쟁반 저격, 급식실 대청소 추가.
- 클리어·목표 발사 수·기술 활용의3개 목표, 총36개 별. 목표는 여러 번의 클리어에 나누어 모을 수 있고 기존 최고 기록을 유지한다.
- 한국 날짜마다 바뀌는 ‘오늘의4판’. 일정은 같은 날짜에 고정되고 재도전은 같은 순서를 유지한다. 출석 재화·에너지 제한은 없다.
- 착지 자세, R 즉시 재시작, 결과의 다음 도전·기록 피드백을 추가했다.

## 보상 광고

본편 첫3판에는 제안하지 않고, 이후 승리 결과에서 추가 코인을 선택하는 provider 연결 지점을 마련했다. 콜백 중복·취소·미준비·세션 상한·쿨다운 및 저장된 보상 영수증 중복 지급을 검사했다.

실제 AdMob SDK·광고 단위·동의 흐름·수익 설정은 아직 연결하지 않았다. 일반 실행에서는 광고 제안을 숨긴다. `TestRewardedFlow.cmd`로 실행하는 별도 테스트 모드는 실제 광고가 아니라는 안내 후 완료/취소 흐름만 재현한다. 이 테스트를 광고 노출이나 수익 검증으로 계산하지 않는다.

## 실제 검증

- Windows64 빌드 성공, 빌드 오류/경고0. 생성 폴더 크기 약365MB이며 ZIP 크기와 다르다.
- Unity 공식 Application Patcher1.3.3으로 `UnityPlayer.dll`의 CVE-2025-59489 패치를 적용했다. [공식 안내](https://unity.com/security/sept-2025-01/remediation). 다른 보안 문제 전체를 인증하는 것은 아니다.
- 패치한 실제 Windows 플레이어를 `-batchmode -nographics`로 실행:12개 검사 통과, 종료코드0. 메인 장면·격리 저장·폰트·개인정보 문서·카트·발사·빠른 도전 진입/돌진/복귀·JSON 재로드 확인. 화면 창을 열지 않았다.
- 기존 관리 코드161개,12판 콘텐츠/일일 일정/별/화면 좌표28개 통과. 콘텐츠 정책은12판×180개 입력(2160회)에서 전 판 승리 경로를 찾았다.
- Unity 네이티브 감사10개 그룹, 신규 보상 광고 흐름13개 검사 통과. 숫자 간 겹치는 검사가 있어 총 품질 점수로 합산하지 않는다.
- 실제 화면을 사람이 조작한 검수, 시각적 완성도·진동·Android 실기기·D1 리텐션·실제 광고 수익은 미검증이다.

증거: `dad-windows-v03-build.txt`, `dad-v03-player-checks.txt`, `dad-v03-native-checks.txt`, `dad-ad-flow-checks.txt`, `dad-content-v2-checks.txt`, `dad-v03-security-patch.txt`.

## 플레이 방법

ZIP을 모두 풀고 `DadWar.exe` 실행. 타이틀 → 대소동 바로 시작. 마우스로 뒤로 당겨 놓으면 반대 방향으로 발사하며, 비행 중 원하는 위치를 클릭하면 추가 돌진한다. R은 같은 판 다시, Escape는 정지다. 상단 번호로 모든 도전을 자유롭게 선택한다.

기존 캠페인·장비·재화는 유지하며, 대소동의 최고 발사 수와 별은 별도 기록한다. 손상된 진행 기록을 읽을 수 없으면 기존 파일을 덮지 않고 복구 안내를 보여준다.
