# 중국 캐주얼·방치형 게임 비주얼 리서치

조사일: 2026-11-04  
대상 프로젝트: **아빠가 학교 짱을 너무 잘 잡음**  
목적: 기존 생성 에셋의 매끈한 SD 일러스트 방향을 재검토하고, 사용자가 제시한 투박하고 우스꽝스러운 모바일 성장 게임의 시각 문법을 구체화한다.

## 1. 결론과 조사 범위

이번 프로젝트에 맞는 방향은 **웹툰식으로 못생기게 그린 아빠 + 단순한 전투 배경 + 크고 직접적인 성장 UI + 과장된 충돌 연출**이다. 화려한 일러스트의 완성도보다 얼굴의 개성, 행동의 가독성, 보상과 다음 목표의 명확함을 우선한다.

‘중국 양산형’은 정식 장르명이 아니다. 이 문서에서는 중국의 미니게임·방치형 성장 게임에서 반복되는 화면 구성을 가리키는 작업 용어로 사용한다. 모든 중국 게임이 같은 화풍을 공유한다는 의미는 아니다.

증거를 다음처럼 구분한다.

- **첨부 관찰**: 사용자가 제공한 이미지 4장을 직접 확인한 내용.
- **공개 화면**: 웹 이미지 검색에 노출된 실제 게임 UI 스크린샷과 그 출처. 광고용 합성 이미지와 구분한다.
- **공식 설명**: 개발사 홈페이지, 공식 입점 페이지, 스토어의 공급자·게임 설명.
- **해석/제안**: 위 자료를 바탕으로 한 디자인 판단. 전환율·유지율 향상의 검증 결과가 아니다.

게임을 설치해 최신 빌드를 플레이한 조사는 아니다. 일부 공개 화면은 2022~2024년 자료이므로 현재 버전의 메뉴와 다를 수 있다. 검색 미리보기에서 확인한 작은 문구·수치는 정확한 구현 명세로 사용하지 않는다. 최신 매출 순위나 ‘성공의 원인’은 이 조사에서 확정하지 않는다.

## 2. 사용자가 준 레퍼런스 해부

### A. 원시인 얼굴 아이콘

**첨부 관찰**: 대머리와 두피 주름, 찌푸린 미간, 작은 눈, 넓은 코, 거친 수염 점, 드러낸 치아가 얼굴을 구성한다. 한 손과 몽둥이가 화면 밖으로 잘려 얼굴 가까이 붙는다. 파란 방사형 배경과 흰 글자·두꺼운 검은 테두리가 작은 화면에서 강하게 대비된다.

**해석**: ‘멋있는 영웅’보다 한 번 보고 기억하는 우스운 인상을 판매한다. 장비의 미세한 장식보다 눈·입·코·무기의 비율이 정체성을 만든다. 이 느낌은 무작위로 선을 삐뚤게 그리는 것만으로 나오지 않는다. 표정과 구도가 의도적으로 과장돼 있다.

**우리 적용**: 아빠의 벗겨진 이마, 반쯤 감긴 눈, 넓적한 코, 수염 자국과 처진 배를 주된 인식 요소로 삼는다. 아이콘은 얼굴과 슬리퍼 한 짝만 크게 배치한다.

### B. 수중 집단 전투

**첨부 관찰**: 작은 원시인 무리가 거대한 적을 둘러싸고 있다. 배경은 청록색으로 묶이고, 위쪽에는 자원과 스테이지 정보, 아래쪽에는 원형 기술 아이콘과 레벨이 있다. 적 위로 흰 숫자와 더 큰 빨간 숫자가 겹친다.

**해석**: 군중의 반복, 보스의 크기, 계속 뜨는 숫자가 전투의 양과 성장감을 만든다. 개별 캐릭터의 정교한 묘사보다 전체 전투의 움직임과 강약이 먼저 보인다. 한 정지 이미지로는 실제 공격 속도나 숫자 표시 빈도를 확정할 수 없다.

**우리 적용**: 아빠는 적보다 조금 크게, 보스는 일반 적보다 확연히 크게 만든다. 충돌 횟수와 연쇄 수를 강조하되, 이동 경로·돌진 예고는 숫자에 가리지 않게 한다.

### C. 공룡과 원시인 군집 홍보 이미지

**첨부 관찰**: 왼쪽 전경의 큰 인물, 중앙의 작은 원시인 무리, 오른쪽의 큰 공룡으로 크기 대비를 만든다. 흙빛 피부·녹색 지형·빨간 공룡이 큰 색 덩어리로 분리된다.

**구분**: 이 이미지는 전투 HUD가 없는 홍보 구도다. 실제 플레이 카메라나 조작 화면을 그대로 증명하지 않는다.

**우리 적용**: 홍보 이미지에서는 아빠 얼굴과 거대한 손을 전경에 쓰고, 날아가는 적과 사물함을 뒤에 배치한다. 실제 게임에서는 전경 인물이 조작 공간을 가리지 않게 별도 구성한다.

### D. 사막 1대1 전투 HUD

**첨부 관찰**: 가운데 큰 캐릭터 2명, 위쪽 재화·스테이지, 왼쪽 바로가기, 아래쪽 기술과 잠긴 메뉴가 있다. 밝은 노란 피해 숫자, 단순한 타원형 바닥 그림자, 작은 코인 오브젝트가 보인다. 회색 자물쇠 옆의 레벨 조건은 다음 해금을 예고한다.

**구분**: 빨간 사각형과 화살표는 설명용 덧그림으로 보이며 원래 게임 UI라고 단정하지 않는다. 에뮬레이터 프레임도 게임 화면 바깥 요소다.

**우리 적용**: 해금 조건과 다음 보상을 명확히 보여준다. 첫 버전에 실제 존재하는 메뉴만 노출하며, 화면에 자물쇠를 많이 채우는 것을 목표로 삼지 않는다.

## 4. 咸鱼之王: 병맛 캐릭터를 평범한 성장 틀에 넣기

**공식 확인**: 豪腾은 삼국 인물을 물고기로 바꾼 황당한 방치형 카드 게임으로 소개한다. 스토어는 편성, 모집, 보물상자, 자동 성장 구조를 설명한다. [공식 게임 목록](https://www.hortorgames.com/game.html), [App Store](https://apps.apple.com/cn/app/id1579028199)

**공개 화면 관찰**: 편성 화면은 우스꽝스러운 물고기 캐릭터를 전투 위치에 놓고, 이름·레벨·강화 수치·별 등급을 붙인다. 캐릭터 선택 카드가 하단에 반복된다. 웃기는 외형과 정보를 정렬하는 UI가 함께 존재한다. [편성 화면 출처](https://www.taptap.cn/moment/406441538306967683)

**해석**: 외형은 낯설지만 카드와 강화 표시는 익숙해 사용법을 추측하기 쉽다. 병맛 캐릭터라는 이유로 인터페이스까지 무질서할 필요는 없다.

**우리 적용**: 아빠·장비는 우스꽝스럽게, 버튼·가격·효과 비교는 정렬해 보여준다. 조끼 색만 바꾼 캐릭터를 늘리기보다 코·턱·배·자세로 인물 차이를 만든다. 대규모 편성과 모집 시스템은 첫 출시 범위에 추가하지 않는다.

## 5. 疯狂骑士团: ‘현재 상태 → 다음 물건’의 짧은 거리

**공식 확인**: 공식 입점 페이지는 상자 개봉을 전면에 내세운다. 중국 공급자도 명시한다. [공식 입점 페이지](https://www.taptap.cn/app/207532)

**공개 화면 관찰**: 장비 화면에 캐릭터, 장비 슬롯 격자, 속성 목록과 큰 보물상자가 함께 들어간다. 슬롯의 색·레벨이 반복되고 화면 상단과 하단에는 별도 콘텐츠 진입점이 있다. [장비 화면 출처](https://www.9game.cn/fkqst/7053246.html), [다른 장비 화면](https://www.downkuai.com/android/173334.html)

**해석**: 복잡한 성장 정보를 보여주면서도 다음 행동은 상자에 집중시킨다. 격자는 수집 진행과 부족한 부분을 비교하기 쉽게 만든다. 많은 속성이 곧 좋은 UX라는 의미는 아니다.

**우리 적용**: 장비 화면은 큰 아빠 1명, 실제 사용하는 슬롯, 선택 장비의 효과, ‘장착’ 버튼으로 구성한다. 슬리퍼·도시락·폴더폰처럼 실루엣만으로 구별되는 물건을 쓴다. 장비 획득 루프를 도입할지는 별도 게임플레이 결정이다.

## 6. 寻道大千: 테마 행동을 성장 화면의 중심에 놓기

**공식 확인**: 나무를 베어 장비를 얻고, 나무와 경지를 올려 더 높은 품질을 해금하는 구조다. 동료·영수 등 추가 육성도 소개한다. [스토어 설명](https://apps.apple.com/cn/app/id6450645450?platform=ipad), [게임 소개](https://www.biligame.com/detail/?id=112909)

**공개 화면 관찰**: 장비 UI는 상단의 경지·주요 속성과 중앙 장비 슬롯을 연결한다. 이벤트 화면은 요구 횟수, 진행량, 보상과 완료 상태를 반복 행으로 보여준다. [장비 화면 출처](https://www.9game.cn/xddq/9163773.html), [이벤트 보상 화면 출처](https://shouyou.3dmgame.com/gl/506163.html)

**해석**: 테마가 반복 입력을 설명하고, UI가 그 행동의 누적 결과를 수치와 해금으로 번역한다. 완성까지 남은 양이 보이는 것이 중요하다.

**우리 적용**: 해금 조건을 ‘전투력 부족’처럼 추상적으로 쓰기보다 ‘벽꿍 20회 / 현재 12회’처럼 행동과 연결한다. 수령 가능한 보상, 진행 중, 완료 상태를 구별한다. 여러 육성 재화와 동료 시스템까지 가져오지는 않는다.

## 7. 공통 문법과 그 역할

아래는 선정 사례와 첨부 화면에 대한 종합 해석이다. 중국 게임 전체의 통계적 결론이 아니다.

| 요소 | 시각적 특징 | 플레이어에게 전달할 정보 | 우리 적용 |
| --- | --- | --- | --- |
| 인물 | 독특한 얼굴, 과장된 체형, 큰 무기 | 누가 어떤 성격인지 | 아빠의 피곤한 얼굴과 비현실적인 손 힘 |
| 채색 | 분리된 색 덩어리, 적은 명암 단계 | 작은 크기에서 실루엣 식별 | 기본색 + 그림자 1단계부터 제작 |
| 배경 | 인물보다 약한 세부, 넓은 바닥 | 싸울 공간과 장소 | 학교 색 띠·사물함·문으로 장소 표현 |
| 전투 정보 | 큰 숫자, 색과 크기의 강약 | 타격과 성장 결과 | 피해량보다 벽꿍·연쇄를 우선 |
| 성장 정보 | 레벨, 품질색, 슬롯 반복 | 현재 상태와 부족한 부분 | 실제 장비 효과와 해금 조건 표시 |
| 진행 유도 | 조건·진행량·보상을 인접 배치 | 지금 할 일과 그 보상 | 임무 1개와 정확한 진척도 |
| 알림 | 빨간 점, 강조 버튼 | 처리 가능한 행동 | 실제 수령·장착 가능할 때만 표시 |
| 수집 화면 | 같은 크기의 카드와 격자 | 비교·보유·미보유 | 장비 도감과 학교 구역 |

외형을 거칠게 만드는 것과 제작 상태가 불량한 것은 다르다. 선이 겹치거나 얼굴이 프레임마다 바뀌고, 글자가 읽히지 않는 것은 의도한 스타일이 아니다.

## 8. 지금 에셋이 목표와 다른 이유

검토 대상: `Assets/DadSchoolBoss/Art/DadHeroMotion-v1.png` 및 기존 에셋 제작 기록.

1. **2.3등신과 매끈한 얼굴**: 눈이 크고 피부가 깨끗해 귀여운 영웅 인상이 강하다. 레퍼런스의 주름·수염·불만스러운 표정과 거리가 있다.
2. **머리카락·옷 주름의 과한 묘사**: 작은 화면에서 의미가 적은 디테일에 비중이 크다. 머리 모양과 채색도 범용 판타지 SD 일러스트에 가깝다.
3. **포즈 간 차이가 작음**: 준비·명중·반동의 실루엣 차이가 약해 정교한 그림을 반복 배치한 느낌이 난다. 연속 동작이 맞는지는 실제 재생 검수가 더 필요하다.
4. **얼굴보다 장식이 먼저 정해짐**: 조끼와 슬리퍼만으로는 이 아빠만의 성격을 충분히 설명하지 못한다.
5. **생성 시트의 셀·접지선 문제**: 1254px 시트의 4등분은 정수 픽셀이 아니다. 후처리 부담이 생기므로 제작용 규격을 먼저 고정해야 한다.

이는 ‘AI 이미지 감지’ 판정이 아니다. 사용자가 말한 AI 느낌을, 목표 화풍과 실제 에셋 사이의 구체적인 차이로 해석한 것이다.

## 9. 우리 게임 아트 디렉션 v2 제안

### 캐릭터

- 키 비율은 우선 3.5~4등신 두 안을 비교한다. 성인 체형을 알아볼 수 있게 한다.
- 아빠: 넓은 이마, M자 머리, 반쯤 감긴 눈, 넓적한 코, 수염 자국, 살짝 나온 배, 구부정한 대기 자세.
- 평상시에는 귀찮은 표정, 타격 직전에는 입술을 다물고 눈을 가늘게, 명중 순간에는 턱·목·팔을 과장한다.
- 외곽선은 512px 작업 캔버스 기준 약 5~8px부터 시험한다. 이는 제안값이며 실기기에서 조정한다.
- 색은 피부·머리·상의·하의·소품 등 큰 덩어리부터 정한다. 그림자는 1단계, 광택과 옷 주름은 최소화한다.
- 적은 키·턱·배·자세·소품을 다르게 한다. 얼굴을 공유하고 옷 색만 바꾸는 제작은 피한다.

### 배경

- 복도의 초록 페인트 띠, 누런 벽, 회색 바닥, 철제 사물함을 장소 기호로 사용한다.
- 바닥에는 인물보다 낮은 대비를 준다. 큰 원근감·빛줄기·질감보다 충돌 가능한 벽과 물건을 선명하게 만든다.
- 그림자는 단순한 반투명 타원으로 시작한다. 충돌 대상은 테두리·형태·파손 단계로 구분한다.
- 기존 위에서 내려다보는 넉백 전투를 유지한다. 첨부 이미지의 횡스크롤 화면을 그대로 가져오는 카메라 변경은 별도 검증 대상이다.

### UI와 글자

- 흰 글자 + 짙은 테두리를 기본으로, 노랑은 큰 보상·강조에 제한한다.
- 버튼은 단순한 직사각형/약한 모서리와 확실한 눌림 상태로 만든다. 장식용 광택보다 효과·조건·가격을 먼저 읽히게 한다.
- 모든 아이콘은 외곽선과 단색 면 중심으로 통일한다. 장면을 통째로 그린 작은 일러스트보다 물건 하나를 크게 쓴다.
- 빨간 점은 받을 것이 있거나 새로 장착 가능한 경우에만 표시한다.
- 실제 탭 영역은 Android에서 최소 48dp를 목표로 검수한다. 폰트 라이선스는 실제 채택 시 확인한다.

### 타격 연출

- 기본: 팔 뻗기 → 한 프레임의 과장된 명중 → 몸 반동 → 복귀. 세부 프레임 수보다 각 단계의 차이를 먼저 만든다.
- 벽꿍: 짧은 흰 명중 섬광, 벽의 금 또는 찌그러짐, 적의 납작한 한 순간을 조합한다.
- 연쇄: ‘3연쇄’ 같은 정보는 적 머리 위 숫자보다 별도 안전한 위치에 크게 띄운다.
- 일반 피해·강한 충돌·연쇄 완성에 크기와 색의 서열을 둔다. 모든 타격을 최대 효과로 만들지 않는다.
- 피드백 시간·숫자 개수·카메라 흔들림 강도는 정지 이미지에서 확인할 수 없으므로 프로토타입의 실험값으로 관리한다.

## 11. 다음 제작의 최소 검증 묶음

한꺼번에 모든 시트를 다시 만들기 전에 다음 4개를 하나의 화면으로 확인한다.

1. 아빠 정면/3분면 대기 1장: 얼굴이 작아져도 성격이 보이는가.
2. 아빠의 준비·명중·반동 각 1장: 무채색 실루엣만 봐도 단계가 다른가.
3. 단순한 복도 배경 1장과 적 2종: 인물·벽·돌진 예고가 분리되는가.
4. 실제 한국어 HUD가 올라간 9:16 화면 1장: 첨부 레퍼런스의 투박함과 우리 전투의 가독성이 함께 보이는가.

승인 기준: 실제 휴대폰 크기에서 3초 안에 아빠·적·전투 공간을 구별한다. 얼굴 확대 없이도 인물이 달라 보인다. 효과를 꺼도 명중 자세가 읽힌다. UI 문구가 정확하고 눌리는 영역이 분명하다. 짧은 사용자 비교로 어느 안이 목표 분위기에 가까운지 확인하며, 이 비교를 유지율 증거로 해석하지 않는다.

작업 규격 제안: 캐릭터는 512×512 독립 프레임, 동일 발 피벗·동일 축척을 먼저 고정한다. 최종 아틀라스는 검수 후 정수 크기로 조립한다. UI 텍스트는 이미지 생성물에 넣지 않고 Unity에서 그린다.

## 12. 재제작 시 전달할 브리프

> 한국 학교 배경의 병맛 모바일 액션 게임. 40대 아빠는 벗겨진 이마, 좁은 눈, 넓은 코, 수염 자국, 살짝 나온 배가 특징이다. 싸구려 웹 만화처럼 단순한 검은 외곽선과 기본색, 그림자 한 단계로 그린다. 얼굴과 자세는 우스꽝스럽고 불균형하지만 프레임 간 얼굴·의상·비율은 일정하다. 슬리퍼는 큰 단일 소품으로 읽힌다. 대기와 명중의 실루엣을 강하게 구분한다. 머리카락과 옷 주름을 촘촘하게 묘사하거나 반짝이는 SD 영웅으로 그리지 않는다. 지정한 게임의 캐릭터·로고·UI를 복제하지 않는다.

이 브리프는 다음 제작의 출발점이다. 이번 작업에서는 새 에셋 생성이나 기존 에셋 교체를 수행하지 않았다.
