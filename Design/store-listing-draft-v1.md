## 2. 콘텐츠 등급 설문(IARC) 답안 초안

설문 문항은 콘솔에서 바뀔 수 있다. 아래는 게임 내용을 사실대로 적은 것이고, 실제 답은 콘솔의 문항을 보며 사용자가 고른다.

| 무엇 | 이 게임 | 근거 |
| --- | --- | --- |
| 폭력 | **있음(만화적, 가벼움).** 사람 모양 인물에게 골프공과 슬리퍼를 던진다 | 맞은 사람은 놀라며 뒤로 뛰어 돌아간다. 피, 상처, 쓰러진 채 남는 모습, 죽음이라는 말이 없다 |
| 피·유혈 | 없음 | |
| 공포 | 없음 | |
| 성적 내용, 노출 | 없음 | |
| 욕설, 비속어 | 없음 | 대사는 "한 방? 간지럽지도 않다!" 같은 허세뿐이다 |
| 약물, 술, 담배 | 없음 | |
| 도박, 사행성 | 없음 | 확률로 주는 보상이 하나도 없다. 상자는 무엇이 들었는지 미리 보여 준다 |
| 이용자 간 소통, 위치 공유, 이용자 제작물 | 없음 | |
| 디지털 상품 구매 | 없음 | 인앱 결제가 없다 |

예상 등급은 적지 않는다. 등급은 설문 결과로 나오는 것이고, 만화적 폭력을 어떻게 볼지는 지역마다 다르다.

**타겟 연령(11/18 밤에 정해짐): 만 18세 이상만.** 콘솔에는 13~15세, 16~17세, 18세 이상 칸이 있었고 사용자가 18세 이상만 골랐다(13~15세 칸에는 국내법의 만 14세 미만이 들어간다). 처음 초안은 이랬다: 13세 이상을 고르는 것을 추천한다. 어린이를 대상으로 고르면 가족 정책(광고 SDK 제한, 추가 심사)이 붙는다. 아빠들의 동네 소동이라는 소재도 어른 쪽이다.

## 3. 데이터 보안(Data safety) 답안 초안

**11/18 밤 변경: 첫 출시에 광고가 들어간다.** 게임 자체는 아무것도 보내지 않지만(로그인 없음, 서버 없음, 측정 도구 없음, 진행 상황은 기기 안의 파일), Google 모바일 광고 SDK가 스스로 수집하고 공유하는 것이 있다. 아래는 Google의 [광고 SDK 데이터 공개 안내](https://developers.google.com/admob/android/privacy/play-data-disclosure)를 기준으로 한 초안이고, **제출할 때 그 안내의 최신 내용을 보고 맞춘다.**

| 문항 | 답 |
| --- | --- |
| 이용자 데이터를 수집하거나 공유하나 | **예**(광고 SDK) |
| 수집·공유되는 종류 | 대략적인 위치(IP 주소에서 추정), 앱 상호작용(광고를 보고 누른 기록 등), 기기 또는 기타 ID(광고 ID 등), 진단 정보 |
| 목적 | 광고 또는 마케팅, 분석, 사기 방지·보안 |
| 전송 중 암호화 | 예 |
| 삭제 요청 방법 | 게임이 직접 모으는 계정 데이터는 없다. 광고 ID는 기기 설정에서 재설정·삭제할 수 있다. 콘솔의 "삭제 요청 방법을 제공하나"에는 "아니요"로 답했다 |

**광고 포함 여부:** 예(보상형 광고).
**광고 ID 사용 신고:** 예(광고 목적).

- Unity 엔진이 스스로 보내는 통계가 꺼져 있는지도 서명 빌드에서 확인한다.
- 측정 도구를 더 넣으면 이 표와 처리방침을 함께 고친다.
- **11/18 밤에 콘솔에 넣고 저장했다.** 넣은 값은 [준비 문서](release-prep-2026-11-18.md) 9절에 있다.

## 4. 처리방침에서 고칠 것 (11/18 밤에 고쳐서 올렸다)

지금 처리방침은 세로 본편과 광고 테스트 버전을 기준으로 적혀 있다. 던지기 게임으로 올리면 아래를 고친다.

- 1절·4절의 "Android 광고 테스트 버전"이라는 말을 실제 출시 버전의 설명으로 바꾼다. Google Mobile Ads와 동의 절차(UMP) 설명은 남긴다. 실제 광고 ID로 바꾸면 "실제 광고 수익은 발생하지 않습니다"라는 문장도 고친다.
- 2절 "기기에 저장하는 정보"를 던지기 게임의 것으로 바꾼다: 깬 판, 가진 돈, 상점에서 산 것, 본 등장 장면, 오늘의 도전조 기록(날짜, 남은 기회, 받은 보상), 난이도 조절 기록.
- 시행일을 올리는 날로 바꾼다.
