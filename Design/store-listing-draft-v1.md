## 2. 콘텐츠 등급 설문(IARC) 답안 초안

설문 문항은 콘솔에서 바뀔 수 있다. 아래는 게임 내용을 사실대로 적은 것이고, 실제 답은 콘솔의 문항을 보며 사용자가 고른다.

| 무엇 | 이 게임 | 근거 |
| --- | --- | --- |
| 폭력 | **있음(만화적, 가벼움).** 사람 모양 인물에게 골프공과 슬리퍼를 던진다 | 맞은 사람은 놀라며 뒤로 뛰어 돌아간다. 피, 상처, 쓰러진 채 남는 모습, 죽음이라는 말이 없다 |
| 피·유혈 | 없음 | |
| 공포 | 없음 | |
| 성적 내용, 노출 | 없음 | |
| 욕설, 비속어 | 없음 | 대사는 "한 방? 간지럽지도 않다!" 같은 허세뿐이다 |
| 약물, 술, 담배 | 없음 | |
| 도박, 사행성 | 없음 | 확률로 주는 보상이 하나도 없다. 상자는 무엇이 들었는지 미리 보여 준다 |
| 이용자 간 소통, 위치 공유, 이용자 제작물 | 없음 | |
| 디지털 상품 구매 | 없음 | 인앱 결제가 없다 |

예상 등급은 적지 않는다. 등급은 설문 결과로 나오는 것이고, 만화적 폭력을 어떻게 볼지는 지역마다 다르다.

**타겟 연령:** 13세 이상을 고르는 것을 추천한다. 어린이를 대상으로 고르면 가족 정책(광고 SDK 제한, 추가 심사)이 붙는다. 아빠들의 동네 소동이라는 소재도 어른 쪽이다.

## 3. 데이터 보안(Data safety) 답안 초안

지금 코드 기준: 광고 SDK 없음, 측정 도구 없음, 로그인 없음, 서버 없음. 진행 상황은 기기 안의 파일에만 저장한다.

| 문항 | 답 |
| --- | --- |
| 이용자 데이터를 수집하거나 공유하나 | **아니요** |
| 전송 중 암호화 | 해당 없음(보내는 데이터가 없다) |
| 삭제 요청 방법 | 해당 없음. 기기의 앱 데이터 삭제로 지워진다 |

- Unity 엔진이 스스로 보내는 통계(Unity Analytics 등)가 꺼져 있는지 서명 빌드에서 확인해야 한다. 켜져 있으면 "아니요"가 틀린 답이 된다.
- 광고나 측정 도구를 넣는 순간 이 표와 처리방침을 함께 고친다.

**광고 포함 여부:** 아니요(첫 출시는 광고 없이 가는 안. 준비 문서 결정 3).

## 4. 처리방침에서 고칠 것

지금 처리방침은 세로 본편과 광고 테스트 버전을 기준으로 적혀 있다. 던지기 게임으로 올리면 아래를 고친다.

- 1절·4절의 "Android 광고 테스트 버전", Google Mobile Ads, UMP 설명을 뺀다(광고 없이 올릴 때).
- 2절 "기기에 저장하는 정보"를 던지기 게임의 것으로 바꾼다: 깬 판, 가진 돈, 상점에서 산 것, 본 등장 장면, 오늘의 도전조 기록(날짜, 남은 기회, 받은 보상), 난이도 조절 기록.
- 시행일을 올리는 날로 바꾼다.
- 게임 안에 처리방침으로 가는 길이 없다(던지기 게임에는 설정 화면이 없다). 정지 화면이나 타이틀에 링크 하나를 넣는다.
