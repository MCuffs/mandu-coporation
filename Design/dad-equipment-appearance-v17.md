# V17 장비 외형 교체와 검수

2026-11-06. V16 검수에서 확인한 덧붙이기 결함을 수정했다. 새 원화 17개를 제작하고 슬롯 합성 방식을 변경했다. 완성 세트 교체가 아니라, 상의 포즈를 선택한 뒤 다른 5개 슬롯을 각각 합성하므로 혼합 장착을 유지한다.

## 적용 변경

| 부위 | 변경 |
|---|---|
| 장갑 | 투명 셀 여백을 제외한 실제 파츠 경계로 UV 수정. 원래 맨손 영역을 교체하고 가까운/먼 손 크기를 포즈마다 구분. 소품을 들면 쥔 장갑으로 변경. |
| 신발 | 실제 파츠 경계로 UV 수정. 원래 신발만 지우고 발목 피부·바지를 보존. 비행 첫 프레임의 신발 중심과 방향도 수정. |
| 상의 | 기존 RGB 재색칠 삭제. 런닝셔츠 8포즈와 낚시 조끼 8포즈를 새로 제작해 실제 옷 형태로 교체. 일반 초록 조끼는 원본 사용. |
| 머리 | 안경 V15 유지. 모자는 낮은 크라운의 착용 전용 원화로 교체하고 원본 비율을 유지하며 머리에 맞춤. |
| 소지품 | 폴더폰/리모컨/신문지마다 그립 좌표·회전 지정. 투명 여백을 제외하고 원본 종횡비를 유지. 맨손이면 좁은 손가락 영역을 소품 앞에 표시. |
| 생활용품 | 효자손/우산/골프채 각각 손잡이를 기준으로 배치. 우산·골프채는 손 아래로 내려오고 효자손은 얼굴을 가로지르지 않게 회전 보정. |

기존 384 캐시를 768 캔버스로 바꿔 장착 때 추가로 해상도를 낮추지 않는다. 캐시 및 손가락 텍스처는 변경/해제 시 정리한다. 시각 크기와 장착 그림은 게임 충돌 범위·장비 효과·경제 수치를 변경하지 않는다.

## 에셋과 출처

`Assets/DadSchoolBoss/Resources/DadV17/`

- `tops/1/`: 런닝셔츠 8개. 기존 캐릭터의 옷만 편집한 투명 스프라이트.
- `tops/2/`: 주머니가 있는 낚시 조끼 8개.
- 포즈 이름: `dad_idle_0`, `dad_idle_1`, `dad_pull_0`, `dad_flight_0`, `dad_flight_1`, `dad_bounce_0`, `dad_land_0`, `dad_hurt_0`.
- `hat.png`: 착용 전용 등산 모자 1개.
- `wear_uv.json`: 기존 V14 장갑/신발 9개 파츠의 실제 alpha 경계.
- `prop_uv.json`, `hat_uv.json`: 손 소품과 모자의 alpha 경계.
- V14/V5 PNG는 유지한다. UV 수정은 alpha를 읽어 메타데이터만 계산했으며 원본 이미지를 재편집하지 않았다.

생성 도구: 내장 image_gen, 투명 배경. 각 원본 포즈를 참조한 편집으로 제작했다. 프롬프트·참조·생성 경로는 `Assets/DadSchoolBoss/Art/V17Outfits/`의 JSON 17개에 보관했다. 최종 PNG는 프로젝트 Resources에 있다. 생성 원화는 그대로 복사하고 Unity가 표시 크기로 임포트한다.

## 검증

- 런타임/에디터 C# 컴파일 성공. 다른 Alley 코드의 기존 미사용 필드 경고 3개만 남음.
- 장비 기능 검사 14개 통과: 원화 16개 로드, 캐시 재사용/해제, 손 영역 교체, UV 로드, 혼합 장비 저장 재로드 등.
- 기존 Play Mode 연결 검사 50개, 경제/에셋 검사 73개 통과.
- 자동 검사는 이미지 품질의 증거를 대신하지 않는다. 아래 Unity 캡처를 별도로 육안 확인했다.
