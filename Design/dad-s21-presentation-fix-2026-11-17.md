# Galaxy S21 Ultra 화면·비행 표현 수정

2026-11-17. 기준 소스 eb30981, 작업 브랜치 `codex/dad-war-s21-presentation`.

## 확인과 범위

사용자가 제공한 106.8초 녹화(540×1200)를 프레임 추출해 확인했다. 기록에는 스토리 이후 본편1-1~1-5, 홈·강화·장비가 담겨 있다. 대소동 전용 HUD는 영상에서 확인하지 못했다. 검은 텍스처 누락도 이 영상에서는 보이지 않는다. 따라서 앞서 발견한 대소동 전용 RotateAroundPivot 문제를 본편 영상의 확정 원인으로 간주하지 않는다.

이번 수정은 본편 진입과 화면 표현이다. 원본 프로젝트의 미커밋 V20, 기획 전환 문서, 게임 경제·저장 형식·스테이지·광고 SDK는 수정하지 않는다. 이 작업 폴더의 코드만 바꿨으며 커밋·푸시하지 않았다.

## 변경

- 타이틀 ‘대소동 바로 시작’과 두 갈래 시작 버튼을 없애고 `게임 시작`/`계속하기` 하나로 통일. 새 플레이어는 기존 스토리→본편, 저장된 플레이어는 홈으로 간다. 이야기 다시 보기 유지.
- 홈의 ‘대소동 도전·12판’ 진입도 제거. 실험용 모드·기록 자체는 삭제하지 않아 이전 기록을 보존한다.
- 본편 캐릭터의 표시 크기를12% 확대. `SlingshotSim.scale`, 충돌 반경, 발사 속도·예측선 계산은 그대로다. 표시 크기와 물리 크기를 별도 상수로 구분했다.
- HUD 높이44→64, 스테이지/발사 글자16→20, 체력11→18. 체력 수치는 바 위쪽으로 분리해 겹침을 줄였고, 정지 버튼50×32→68×48로 확대했다. 기존 safe-area 좌표 변환과 전체 경기장은 유지한다. 휴대폰 화면을 잘라서 빈 공간을 없애는 방식은 쓰지 않았다.
- 비행 방향의 거의 수직인 구간에서는 좌우 반전 상태를 유지하고, 몸 기울기를±65도 이내로 제한. 프레임당540도/초 한도로 각도 전환을 완화한다. 새 판에서 표시 상태를 초기화한다.
- 비행 몸 중심을 확대된 서 있는 몸의 반높이 기준으로 맞춰 발사 때의 표시 높이 변화를 줄인다. 벽 반동 접점도 같은 표시 배율로 계산한다.
- 쓰러진 적을 회전하며 솟구치는 `fly` 포즈 대신 짧은 `hurt` 포즈로 표시. 최근 최대3명만, 불투명도65% 이하, 수명0.25초부터는 표시하지 않는다. 살아 있는 적의 피격 기울기도±12도로 제한하고 과도한 표시 상승량을 줄였다. 실제 적의 위치·체력·연쇄 판정은 변경하지 않았다.
- 안경 프레임을 눈 앵커 중심으로90% 크기로 조정. 장갑과 손 교체 마스크를 함께 축소. 폴더폰/리모컨 높이110→84, 신문115→100, 효자손180→150, 우산/골프채170→145. 손 앵커·투명 UV·몸과 동일한 변환을 유지한다. 소품 위 손가락 레이어가 없을 때 null 텍스처를 그리지 않게 보호했다.

- 런타임 전체를 Unity 번들 Mono로 `SLING_HEADLESS` 컴파일해 검사했다. Android SDK·IL2CPP·실제 렌더링 검사는 아니다.

## 배포 상태와 남은 확인

**수정 소스이며 새 APK는 아니다.** 로컬에는 Unity2021.3.2와 MacStandaloneSupport만 있고, 기존 APK를 만든 Windows Unity6000.1.5f1/Android 빌드 환경이 없다. 기존 설치 APK는 이 수정으로 자동 갱신되지 않는다. 엔진을 임의 설치/업그레이드하거나 Unity/플레이어 창을 띄우지 않았다.

후속 Android 빌드는 이 브랜치의 소스 변경을 기존 Windows Android 빌드 사본에 반영하고 SDK·서명·버전 코드를 검증해야 한다. 기존 설치와 같은 테스트 서명을 유지하고 사용자 저장을 삭제하지 않는다. 수정 APK의 실제 S21 Ultra 재생 검수 전에는 화면 문제가 해결됐다고 확정하지 않는다.

S21 재검수 순서: 타이틀 시작 버튼1개 → 새 저장에서 스토리/기존 저장에서 홈 →1-1 출동 → 상하·대각·벽 반동·착지 → 다중 제압 때 표시3명 상한 → 안경·장갑·소품 조합 → 정지/복귀. HUD가 기기 안전영역 밖으로 나가지 않는지와 확대된 원화·실제 충돌의 체감 차이도 확인한다. 남은 큰 빈 공간은 경기장 자체를 바꾸는 별도 레벨/카메라 설계 문제이며 이번에 임의로 잘라내지 않았다.

## 후속: 전투 글자 밀도 축소

사용자의 ‘너무 정신없다’는 피드백에 따라 전투 중 읽어야 하는 텍스트를 줄였다.

- 제거: 적 머리 위 타격/치명타 문구, 중앙 대형 연쇄/개그 문구, 노란 스테이지·이벤트 배너, 매 발사 결과 해설, 상시 별 목표 안내, 착지/판정 대기 문구, 조준 퍼센트, 벽 반동 횟수 글자.
- 유지: 상단 스테이지 번호·체력·발사 수·정지, 적 잔여 수, 작은 하단 `연쇄 N`, 보스 체력과 짧은 공격 기회 안내. 타격 효과·소리·진동과 전투 규칙은 유지한다.
- 첫 조작 안내는1-1 첫 발사 전 최대8초, 짧은 한 문장과 손가락 그림만 표시한다. 이후 스테이지에는 같은 문장을 반복하지 않는다. 새 적의 최초 소개 화면은 유지한다.
- 홈·장비 화면의 반복 대사와 장식성 설명도 일부 제거했다. 장비 효과·희귀도 확률·결과 정보는 유지한다.
- 글자용 팝업/배너/발사 요약의 사용하지 않는 상태와 생성 코드도 정리했다. 창 없는 규칙·표시 검사169개 통과. 실제 Android 렌더링과 변경 APK는 여전히 미검증/미생성이다.
