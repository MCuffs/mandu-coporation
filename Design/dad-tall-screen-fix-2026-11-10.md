# Q-01 대소동 긴 화면 배경 수정

2026-11-10. `DadFunLab`이540×960 영역 밖에도 화면 전체 배경을 그리도록 수정했다. 상하 안전 영역이 비대칭이어도 전체 화면의 논리 범위를 계산한다. 버튼·조작 좌표는 기존 안전 영역을 유지한다.

배경은9:16 기준 원본 y=210 크롭에서 화면 높이만큼 연장하며, 논리1px당 원본2px 배율과 좌우 벽 위치를 유지한다. 배경을 무조건 ScaleToFill하거나 가로까지 확대해 충돌선과 어긋나게 하지 않는다. 원본보다 긴 부분은 기존 Clamp 설정으로 가장자리를 연장한다.

`BackgroundUv()`에 대해 높이960,1170,1200(비대칭 상단 포함)에서 기준 y=0이 원본 y=210에 놓이고 배율2를 유지하는지 검사했다. 기존8판 전략 검사와 합계19개 통과. 증거는 `dad-content-v2-checks.txt`의 추가 좌표 검사다.

실제 렌더링·노치·제스처 안전 영역·화면 회전은 아직 기기에서 확인하지 않았다. 이 수정은 배경의 빈 영역을 채우며 물리 경기장을 기기마다 늘리는 변경은 아니다.
