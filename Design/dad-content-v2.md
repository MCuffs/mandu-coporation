# 아빠 대소동 — 콘텐츠 확장 v2

2026-11-09. 상태: **코드·에셋 연결 및 관리 코드 검증 완료, 실제 화면/터치/Android 미검증**. 재미와 매출이 검증된 출시판은 아니다.

## 플레이 구조

메인 홈의 **대소동 도전 · 8판**에서 진입한다. 홈 화면을 일시적으로 비활성화하고 독립 오브젝트에서 실행하며 집으로 버튼으로 복귀한다. 장면 로드나 Build Settings 추가가 필요 없다. 단독 검수는 기존 `Assets/DadFunLab.unity`에서도 가능하다. 현재 열려 있는 Unity나 플레이어를 자동 실행하지 않았다.

기존 캠페인·장비·재화·보상은 그대로 보존했다. 도전 최고 발사 수만 `DadContentV2.Best.<내부ID>`의 별도 PlayerPrefs에 저장한다. 최고 기록을 악화시키지 않고, 이미 깬 판은 상단에 별로 표시한다. 모든 도전은 자유롭게 선택할 수 있고 결과에서 다음 도전/즉시 재시도가 가능하다. 광고·입장료·체력 소모는 없다.

| 1 | 날다가 한 번 더 | 첫 충돌 뒤 반대쪽 상대를 탭해 방향 전환 | 2 | 2 |

정밀한 1발 정답 찾기를 시작점으로 쓰지 않았다. 추가 돌진을 첫 판부터 소개하고, 실패해도 두 번째 발사로 수습하게 했다. 일부 상대는 정지·체력1인 실험용 배치이며, 캠페인의 실제 AI와 성장 밸런스를 모두 대신하지 않는다.

## 새 상호작용과 표현

- **추가 돌진:** 지원 판에서 발사마다 한 번, 비행 중 탭한 방향으로 돌진. 첫 제압 뒤 짧게 느려져 다음 대상을 고를 시간을 제공한다. 터치 취소·포커스 상실은 돌진/발사로 처리하지 않는다.
- **급식 카트:** 아빠가 닿으면 진행 방향으로 밀려나며 상대를 쓸어버린다. 같은 상대에게 중복 피해를 주지 않고 벽 반사·감속·정지 후 실패 판정을 처리한다.
- **반사 매트:** 화살표가 가리키는 위쪽으로 발사한다. 재충돌 쿨다운으로 한 접촉이 매 프레임 재발동하지 않게 했다. 실제 원화의 방향과 기능을 일치시켰다.
- **가독성:** 추가 돌진 준비는 청록 테두리, 사용 순간은 노란 확산 테두리로 표시한다. 하단에 남은 상대·사용 발사/한도·연쇄·최고 발사 기록을 표시한다.
- **입력 안정성:** 비행 중 재발사·한도 초과 발사·돌진 중복을 거절한다. 일시정지와 앱 전환 시 당김 입력을 취소한다. 기존 캠페인 음악은 진입 시 정지했다가 홈 복귀 때 복구한다.

## 에셋 제작·적용 요청

아래 **2개 PNG는 새로 생성한 래스터 원화**다. 프롬프트는 `dad-content-v2-generation.json`, 크기·알파·해시는 `dad-content-v2-assets.json`에 보존했다. 편집되지 않은 생성 파일을 프로젝트로 복사했고, 알파를 확인했다. 돌진 링은 읽기 쉬운 단순 도형으로 코드에서 그린다.

| 파일 | 적용 위치·규칙 |
| --- | --- |
| `Assets/DadSchoolBoss/Resources/DadContentV2/lunch_cart.png` | `DadFunLab.Awake()`에서 로드, `OnGUI()`에서 카트 위치 기준116×116 캔버스 표시. 단순 실험 도형을 교체 |
| `Assets/DadSchoolBoss/Resources/DadContentV2/rebound_mat.png` | 같은 로더, 매트 위치 중심96×96 표시. 매트의 화살표는 위쪽 발사 기능을 의미 |

원본은 각각1254×1254 RGBA, Unity 최대1024·밉맵 끄기·Clamp다. `.meta`는 신규 GUID로 준비했다. 기존 캐릭터·복도·효과음은 재사용했다. 현재 소스에 연결돼 있지만 Unity 임포트·기기에서 시각적 접점 확인은 남았다. 누락 시 개발용 대체 도형이 나온다.

개발 적용 대상:

1. `DadContentChallenge.cs`: 홈 진입/복귀와 기존 전투·음악 비활성화/복원.
2. `DadHomeScreens.cs`: 홈 버튼 한 개 추가.
3. `Slingshot/DadFunLab.cs`: 콘텐츠 선택·표시·입력·독립 기록.
4. `Slingshot/DadFunLabModel.cs`:8판 구성·발사 한도·돌진·카트·매트.
5. 위 두 Resources PNG와 `.meta`를 함께 가져온다. 기존 캠페인 `SlingshotSim` 수치를 덮어쓰지 않는다.

## 실행 검사와 결과

Windows에서 `python Tools/check_dad_fun_lab.py`로 기존 슬링샷·난이도·실험 회귀161개 통과. `--content`로 신규16개 통과. 전체 런타임 소스는 설치된 Unity2021.3.2f1의 Mono와 Unity DLL로 컴파일했다. 기존 Alley 미사용 필드 경고3개 외 오류 없음.

신규 전략 시험은 내부 ID별180개 입력 정책, 합계1440회다. 최초 각도·세기, 이후 가까운 상대/카트 조준과 한 번의 방향 전환을 사용했다. **8판 모두 재현 가능한 승리 경로**를 찾았다. 매트의 위쪽 발사, 발사마다 돌진1회 회복, 예산 초과 거절, 초기화·잘못된 인덱스 보정·8판 순서도 검사했다. 상세 입력은 `dad-content-v2-checks.txt`.

이 결과는 사람의 성공률이나 재미 점수가 아니다. 관리 코드 시험은 실제 마우스/손가락, 렌더링, 효과음 감상, 앱 전환 콜백과 PlayerPrefs의 기기 저장 동작을 검증하지 않는다. 신규 홈 버튼·복귀·동시 GUI 여부도 Unity 실검수가 필요하다. 과거 v1의 한 발 전략 보고서는 참고 기록이며 현재8판의 사용자 흐름은 이 문서를 따른다.
