# 아빠 전쟁 — 시작 화면·시나리오 에셋 v11

## 사용자 확정 흐름

검은 배경 + **Mandu Corporation** → **아빠 전쟁** 시작 화면 → **게임 시작** 누름 → 의리 테스트 시나리오 영상 → 첫 전투.

시작 버튼을 누르기 전에는 시나리오를 자동 재생하지 않는다. 회사명 표기는 위 대소문자와 띄어쓰기를 그대로 사용한다. 회사명 뒤에 아이콘이나 임의 슬로건을 붙이지 않는다.

## 제작 방식

- 회사 스플래시: 검정 화면과 흰색 라이브 텍스트. 제공 SVG는 1080×1920 시각 기준이며 Unity에서 SVG를 그대로 읽도록 요구하지 않는다.
- 타이틀: 글자/버튼 없는 세로 일러스트 + 런타임 제목 **아빠 전쟁**, 버튼 **게임 시작**.
- 시나리오: 독립된 원화 6장을 사용한 컷 연출. 이번 납품은 영상 원화이며 완성된 MP4, 성우, 애니메이션 동영상은 포함하지 않는다.
- 그림 안에 회사명·게임 제목·대사·버튼을 생성하지 않는다. 문자는 선명한 폰트로 별도 렌더링한다.
- 제작 도구: 내장 image_gen. 프롬프트와 원본 경로는 manifest에 기록한다.

## 인물 고정

아빠는 기존 `DadV5/chars/dad/dad_idle_0.png`의 얼굴·벗겨진 이마·수염·배·올리브 조끼·누런 런닝·어두운 바지·삼선 슬리퍼를 유지한다. 전신을 미화하거나 영웅형 근육질로 바꾸지 않는다.

아들: 짧은 검정 머리, 크림색 티셔츠와 짙은 남색 목/소매 테두리, 파란 바지, 흰 운동화. 이 외형은 컷 간 연속성을 위한 이번 제작안이다. 아들은 장난의 당사자이자 말리는 역할이며 전투 대상이 아니다.

대사/길이는 제작 제안이다. 검은 여백이나 말풍선을 이미지에 굽지 않는다. 자막은 화면 하단 별도 레이어. 1–3번은 정적 컷의 짧은 확대, 4번은 빠른 컷, 5번은 잠깐 정지, 6번은 이동감을 주어 반응의 차이를 만든다. 완성 영상으로 렌더링할 때 실제 대사 읽기 속도로 길이를 조정한다.

## Unity 연결 시 기준

- 스플래시 제안: 페이드 인 0.35초 + 유지 1초 + 페이드 아웃 0.35초. 이후 시작 화면. 실제 엔진 시작 화면과의 순서는 빌드에서 확인한다.
- 신규 플레이: 게임 시작 → 시나리오 → 첫 전투. 기존 저장이 있는 경우 홈/이어하기로 연결하는 정책은 구현 때 명시한다. 시나리오 다시보기/건너뛰기를 지원하는 방향이다.
- 원화는 화면 비율을 확인해 Fit 또는 제한된 Crop. 중요한 얼굴과 손이 잘리지 않게 하고, 상단 건너뛰기/하단 자막 안전 영역 확보.
- 텍스처는 원본 보관 폴더에 저장하며 자동 런타임 연결됐다고 간주하지 않는다. 각 원화의 실제 크기는 manifest가 기준.
- UI가 전체 그림처럼 보이는 걸 막기 위해 제목/버튼/원화 레이어 분리. 눌림/비활성/로딩 상태는 코드로 제공.
