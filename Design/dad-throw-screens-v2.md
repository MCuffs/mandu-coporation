# 가로 화면 구도 v2 — 작은 인물과 넓은 여백

2026-11-17. 사용자 피드백: 캐릭터·오브젝트가 커서 화면이 꽉 차 보이므로 조금 더 넓은 화각을 원함.

## 변경

- 시작 원화와 거리 배경을 imagegen 편집으로 더 먼 카메라 구도로 재제작. 기존 그림을 테두리 안에 축소하지 않고 집·하늘·도로를 연속된 환경으로 넓혔다. 생성 결과의 인물 축소율은 이미지 전체에 일률적인 수치로 보장하지 않는다.
- 완료 인물 박스550→410(약25% 축소), 실패540→405(25% 축소), 전투 배치 미리보기의 인물310→250(약19% 축소). 발 아래 여백을 맞춰 다시 배치했다.
- 제목116→94(약19% 축소), 결과 패널 폭500→460, 일시정지 패널430→390. 제목/인물/패널 사이 거리를 늘렸다.
- 주요 버튼은 높이72를 유지했다. 배경과 원화가 작아져도 누르는 영역까지 함께 축소하지 않는다. 문구와 상태는 v1과 같다.

## 검수와 적용 범위

새 원화2개와 최종4면 미리보기를 직접 열어 확인했다. 네 개 화면은1280×720 오프스크린 HTML 렌더다. 배경이 넓어진 만큼 인물이 작아져도 얼굴 실루엣과 버튼 문구가 구분되는지 디자인 시안 수준으로 확인했다.

실제 게임 카메라·물리 좌표·투사체·적 충돌·Unity 코드는 수정하지 않았다. 이 요청은 직전 메뉴 디자인 시안을 기준으로 반영했으며 **Unity/Android에 적용됐다는 뜻이 아니다**. 새 배경의 바닥/집 경계는 런타임 연결 때 다시 측정해야 한다. 기기 실물 가독성·터치 검수는 미완료다. Unity 창·플레이어 실행, APK 생성, 커밋·푸시는 하지 않았다.
