# 아빠 전쟁 — 오늘의 도전조 에셋 요청서 v1

2026-11-18. 사용자 요청: "오늘의 도전조에 사용할 에셋 요청서도 만들어주세요."
[오늘의 도전조 v1](dad-throw-daily-v1.md)은 그림 없이 글자와 네모 칸으로 들어가 있다. 이 문서는 **지금 게임에 들어간 화면 그대로**를 기준으로, 그 자리에 들어갈 그림과 소리를 적는다.

[화면 에셋 요청서 v4](dad-throw-asset-request-v4.md)와의 관계:

- v4는 화면을 만들기 전에 쓴 것이라 도전장 안의 자리가 지금 코드와 다르다. **자리와 크기는 이 문서가 앞선다.**
- v4에 이미 있는 그림은 **같은 파일 이름**을 쓴다. 두 번 그리지 않는다. 표의 "어디" 칸에 `v4 4K`처럼 적었다.
- 공통 규칙(형식, 화풍, 색, 납품 폴더, manifest, 반려 기준)은 v4 3절과 v2 2절을 그대로 따른다. 그림 안에 글자와 숫자를 넣지 않는다.

**2026-11-18 밤 납품·적용:** 그림 42장과 소리 6종이 들어왔고([납품 문서](daily-assets-handoff.md)), 그중 그림 39장과 소리 6종을 게임에 연결했다. 아래 표의 "임시 처리"는 지나간 이야기다. 남은 것은 `rule_card_back`, `envelope_closed`, `unlock_daily` 세 장과 6절의 결정이다.

## 5. 반려 기준 (v2·v3·v4에 더하는 것)

- 규칙 아이콘 열두 장을 30px로 줄여 나란히 놓았을 때 두 장이라도 헷갈리면 반려한다.
- 아이콘과 카드에 글자, 숫자, 사람 얼굴이 있으면 반려한다.
- 상자 세 가지가 60px에서 색과 모양으로 구분되지 않으면 반려한다.
- 안개가 회색이거나, 왼쪽 가장자리가 직선이거나, 가장 짙은 곳에서 뒤가 전혀 안 보이면 반려한다.
- 늘려 쓰는 그림(종이, 카드 틀, 표시 판)의 가운데에 무늬가 있으면 반려한다.

## 6. 사용자가 정할 것

1. **상자 세 가지를 보상 세 줄에 하나씩 쓴다**(깨기 = 나무, 대문 한 번 이하 = 양철, 한 공에 15명 = 금색). v4는 상자를 여러 화면이 같이 쓴다고만 적었고, 어느 보상에 어느 상자인지는 이 문서에서 처음 정했다.
2. **「공만」일 때 신발 버튼을 지우지 않고 회색으로 남겨 금지 표시를 얹는다.** 지금은 버튼이 사라진다. 버튼 자리가 비면 화면이 달라 보여서 남기는 쪽을 추천한다.
3. **도전장을 열 때 카드가 뒤집히며 나오는 연출**(`rule_card_back`, P1)을 넣을지.

정해지지 않아도 P0 그림은 그대로 그릴 수 있다.
