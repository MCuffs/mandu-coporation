# 아빠 전쟁 — 대문 터치 대항전 / 스토리·연출 제작안 v2

2026-11-17. 사용자가 대문 터치 대항전 제안 이후 계속 진행을 요청하여 상세화했다. 등장인물 이름/성격은 홈페이지 설정, 경기·대사·사건은 이번 게임의 창작 각색이다. 기존 v1 대본은 보류 기록으로 남긴다. Unity/홈페이지/게임 코드를 변경하는 문서가 아니다.

## 1. 반드시 설명해야 하는 인과

**왜 집 앞인가?** 칠석이 자기 집 대문을 승리 목표로 지정했기 때문이다.

**왜 상대가 돌진하는가?** 때리러 오는 침입자가 아니라 대문을 먼저 만지면 이기는 도전자들이다.

**왜 물건을 던지는가?** 만수가 장난감 골프공을 건네고 칠석이 ‘이걸 피해서 들어오라’는 황당한 방어 규칙을 제안한다. 지호 아빠가 받아들인다. 신발은 칠석의 과잉 대응 개그이며, 이후 다른 생활 물건도 대회의 만화적 도구가 된다.

**왜 계속 오는가?** 만수의 촬영에 철수까지 말려들고, 소문을 들은 동네 아빠들이 줄을 선다. 스테이지는 도전조, 웨이브는 출발 간격이다. 무한히 증원되는 적대 조직은 없다.

**무엇을 지키는가?** 가족의 생명이 아니라 ‘우리 아빠가 제일 세다’는 만수의 허세와 그걸 받아 버린 칠석의 자존심이다. 초반에는 아이 편을 들어주는 아빠의 따뜻함, 진행에서는 어른들의 유치함이 웃음의 중심이다.

## 2. 가족의 행동과 성장

| 인물 | 발단 | 진행 | 결말 |
|---|---|---|---|
| 칠석 | 아들 부탁에 따라나왔다가 도발에 승부를 건다 | 점점 큰 물건을 꺼내며 과몰입 | 수진 앞에서 체면을 내려놓고 같이 정리 |
| 만수 | 반응 촬영 장난, 우리 아빠가 세다고 허세 | 일이 커져 카메라를 내리고 형에게 도움 요청 | 자기가 먼저 장난쳤다고 인정, 직접 치움 |
| 철수 | 장난을 눈치채고 제지 | ‘말로 하라’고 했다가 경기 규칙 기록 담당이 됨 | 휴대폰 대신 빗자루를 쥐여주며 동생과 정리 |
| 수진 | 소동을 모르는 동안 자기 시간을 보냄 | 초기에는 화면 밖, 반복 잔소리 NPC 아님 | 자기 공간을 멋대로 경기장으로 쓴 모두에게 정리 요구 |
| 지호 아빠 | 아들 부탁을 듣고 나왔다가 칠석을 도발 | 첫 도전자, 패해도 원한 없이 다음 도전자에게 허세 | 승패와 별개로 칠석과 함께 치움 |

홈페이지 출처: [칠석네 가족 소개](https://mcuffs.github.io/bluemushroom/), 2026-11-17 열람. 희망퇴직 같은 배경은 인물의 생활감으로만 남기고 오프닝 설명 자막으로 늘어놓지 않는다. 가족의 이름/옷/관계는 유지한다. 공개 홈페이지의 기존 학교 슬링 액션 소개가 새 버전으로 바뀌었다고 주장하지 않는다.

## 3. 경기 규칙과 게임 시스템 연결

기본 규칙은 ‘안쪽 대문을 만지면 도전자 승리’다. 첫 게임 UI의 HP5는 **이번 도전조에게 허용된 대문 터치5회**로 각색한다. 골프공에 맞은 도전자는 그 차례에서 탈락해 뒤로 빠진다. 피격자가 기절하거나 죽었다는 문구는 없다. 신발은 앞 도전자들을 물러나게 해 뒤 무리와 합치는 도구다.

| 게임 요소 | 이야기 의미 | 표현/제약 |
|---|---|---|
| 적 접근 | 대문 터치 도전자 | 공격 주먹/무기 없는 성인 아빠 |
| HP 한 칸 감소 | 대문1회 터치 허용 소모 | 대문에 작은 손바닥 반응, 집 파손 금지 |
| 처치 | 이번 차례 탈락 | 사망·살해 문구 대신 퇴장 |
| 스테이지 클리어 | 해당 도전조 모두 마침 | `이번 조 끝!` 등 짧은 문구 후보 |
| 코인 | 게임적 클리어 보상 | 참가비/도박 판돈으로 설명하지 않음 |
| 강화 | 장난감 투척 요령 개선 | 체벌·치명상 상승 서사 없음 |
| 골프공 | 만수의 말랑한 장난감 공 | 현재 흰 공 그림 재사용, 실물 골프공의 위력 묘사 없음 |
| 신발 | 칠석의 낡은 슬리퍼 | 과장된 넉백, 상처 없음 |
| 자동차 후보 | 아직 서사 미해결 | 실제 차를 사람에게 던지는 것으로 확정하지 않음. 장난감/풍선차 후보 별도 검토 |

목표물은 장식 대문이 아니라 실제 누수 경계와 겹쳐야 한다. UI에서 기존 ‘집 파괴/방어력’ 문구를 남기면 설정이 충돌한다. **이번에 모델/문구를 바꾼 것은 아니며 런타임 구현 시 수정 대상이다.**

로고→타이틀→시작 누름→오프닝→첫 조준 순서. 기존 18초보다 길어졌지만 발단·도발·규칙·동의가 모두 보여야 한다. 이후 15초 축약안으로 비교한다. 시간을 맞추려고 글자를 빨리 넘기지 않는다.

24초가 끝나도 자동 공격하지 않는다. 첫 조준 전에는 스폰 시계를 멈춘다. 건너뛰기는 동일한 StageStart 초기화 경로를 정확히1회 실행한다. 컷 전환 중 백그라운드로 가면 시간도 멈춘다. 마지막 컷에서 대문 위치/아빠 크기가 바뀌면 안 된다.

### 15초 축약 버전

0~4초 만수 부탁+허세 →4~7초 도발 →7~11초 칠석 규칙+상대 수락 →11~15초 ‘이미 말로 했다’와 조준 연결. 공이 만수의 장난감이라는 사실은 4번째 컷에서 화면 내 물건과 짧은 말 `내 장난감으로?`로 전달할 수 있다. 규칙 동의 장면은 삭제하지 않는다.

## 6. 1장 결말 — 12초 제안

0~3초 만수가 휴대폰을 내린다: `내가 먼저 장난쳤어.`

3~6초 칠석: `…그래도, 아빠가 네 편은 돼야지.` 철수는 어른들 쪽을 보고 한숨.

6~9초 수진: `편은 됐고. 다 같이 치워.` 상대 아빠들도 뒤에서 슬쩍 돌아오며 물건을 줍는다.

9~12초 칠석: `밥은?` 수진: `치우고.` 가족과 이웃이 함께 치우는 넓은 마무리 컷.

따뜻한 대사는 한 줄이면 충분하다. 이웃과 가족이 함께 치우는 **마지막 전용 포즈는 아직 없다**. 현재 미리보기는 standing pose로 타이밍만 보여준다. 나중에 정리 원화1장을 제작할지 움직임3포즈를 만들지 비교한다.

## 8. 실제 애니메이션 제작 단계

1. 이미지/알파·셀 경계 검사. 불합격 시트는 보정본으로 교체한다.
2. 각 셀을 Sprite Editor에서 분리하고 발/중심 피벗을 지정한다. 전체 시트를 한 스프라이트로 쓰지 않는다.
3. Timeline 또는 작은 상태 시퀀서에서 컷/자막/이동/사운드를 연결한다. 최초에는 관절 변형 없이 컷아웃만 움직인다.
4. 게임과 같은 안전 영역에 하단2줄 자막/상단 건너뛰기 배치. HTML 시안과 실제 터치 타깃을 별도 확인한다.
5. 오프닝 완료/건너뛰기 모두 StageStart 하나로 전달, introSeen 저장은 실패 복구 고려.
6. 최종 전투 화면과 이어지는 손·공·대문 위치를 실기기 캡처로 비교한다.

필요 후속: 공을 건네는 만수 손/칠석 받는 손, 전화 내림, 수진 문간 등장, 정리 자세, 눈/입 분리. 현재 납품은 이 모든 프레임이나 완성 동영상이 아니라 **연출 키자산과 타이밍 시안**이다.

## 9. 사람에게 확인할 질문

첫 재생 후 설명 없이 ‘왜 대문으로 뛰어오나요?’, ‘맞으면 어떻게 되나요?’, ‘아빠는 왜 공을 들었나요?’를 묻는다. 도전·탈락·방어 도구가 답에 나오지 않으면 대사를 더 붙이기 전에 컷 순서/대문 강조/상대의 수락 장면을 수정한다. 첫 플레이 조작을 기다리기 답답하다는 반응이 많으면15초판으로 줄인다.

검수 체크: 인물 일치 / 대문과 누수 경계 일치 / 상대 수락 존재 / 아이 전투면 배제 / 글자 구움 없음 / 이미지 셀 분리 / 건너뛰기 중복 없음 / 포커스 상실 정지 / 음성 없이 이해 / 첫 조준 대기.
