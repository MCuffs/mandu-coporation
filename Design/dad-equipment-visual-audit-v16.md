# 장비 외형 검수 V16

2026-11-06. 판정: 현재 장비 외형은 상업용 품질 검수 불합격. 안경 위치 수정만으로 해결되지 않는다.

## 검수 범위와 증거
V15 Unity Play Mode 캡처의 일반/희귀/최고 전부 장착, 혼합 홈, 전투 대기·조준·비행을 다시 육안 검수했다. V14 파츠 아틀라스, V5 모자/소지품/생활용품 원본, DadOutfitRenderer와 UV 메타데이터를 확인했다. 이번 검수에서는 게임 코드와 에셋을 변경하지 않았다.

6슬롯×3등급의 연결 구조를 확인했지만 4^6 조합 전체, 8포즈 각각의 모든 장비 및 Android 실기기를 검증한 것은 아니다. 튕김/착지/피격은 코드 점검 대상으로, 해당 장면의 시각 합격을 선언하지 않는다.

## 공통 원인 (코드 근거)

1. **몸 교체 없이 덧붙이기**: Body는 신발만 색 기반 사각 영역으로 지운다. 손·머리에는 원래 픽셀을 제거하는 마스크가 없다. Layers는 완성된 몸 위에 장비를 그린다. 장갑 속 맨손이나 모자 아래 머리가 남는 구조다.
2. **중심 좌표가 착용 피벗을 대신함**: Sprite는 이미지 중심을 앵커에 놓는다. 손목·그립·발뒤꿈치·모자 안쪽 기준이 없고 파츠의 투명 여백에도 영향을 받는다.
3. **종횡비 강제 변형**: Gear는 모든 소지품 86×118, 모든 생활용품 106×266을 사용한다. 아이템별 원본 비율이나 대각선 방향을 고려하지 않는다.
4. **양쪽 팔다리 미분리**: 신발은 양쪽에 같은 파츠와 크기를 사용한다. 주먹 장갑은 좌우 반전도 동일하다. 한 장의 원근 그림을 모든 포즈에 돌려 쓰기에는 한계가 있다.
5. **상의 형태 불일치**: IsCoat RGB 조건으로 크림/갈색을 입히므로 조끼 재단·주머니·앞섶은 바뀌지 않는다.
6. **장착 시 선명도 변경 가능**: 원본은 768 캔버스인데 Body 캐시는 384로 생성된다. 신발/상의 장착 여부에 따라 본체 해상도까지 달라지는 부수효과가 있다. 실제 저해상도 화면에서의 영향은 별도 비교 필요.

## 수정 순서

1. 손·발부터 교체 구조 확립. 기본 몸의 해당 부위를 지우는 수동 마스크와 손목/발목 기준 피벗을 함께 제작한다. 부품 크기만 키워 가리는 방식은 피한다.
2. 소품 6종의 착용 전용 그림 제작. 그립 피벗, 손가락 앞 레이어, 소품 뒤 레이어를 정한다. 인벤토리 아이콘과 분리한다.
3. 런닝셔츠와 낚시 조끼의 실제 형태 제작. 원래 조끼가 남지 않는 몸통 교체 영역을 정의한다.
4. 모자를 앞/뒤로 분리하고 머리와 겹치는 부분을 설계한다.
5. 기본 대기 2프레임에서 각 슬롯 단독 18종을 먼저 합격시킨 뒤 혼합과 전투 6포즈로 확장한다. 캐릭터 선 두께·채색·광원·원근을 통일한다.

전체 세트 캐릭터 3장을 제작하는 방식은 슬롯 혼합을 지원하지 못하므로 현재 장비 시스템과 맞지 않는다. 포즈마다 18개 전용 그림을 무조건 만들기보다, 공유 가능한 포즈와 별도 그림이 필요한 포즈를 먼저 나눈다.

## 다음 합격 조건

- 미장착/각 아이템 단독/전체 등급 세트/혼합을 같은 크기로 비교한다.
- 눈/손/발이 중복되지 않고 손목·발목 연결에 틈이 없다.
- 그립 위치가 손바닥 내부에 있고 손가락이 손잡이 앞을 덮는다.
- 아이콘과 착용 형태가 일치하며 원본 비율이 왜곡되지 않는다.
- 대기 2종/당기기/비행 2종/튕김/착지/피격 및 좌우 반전에서 연결이 유지된다.
- 실제 전투 표시 크기와 확대 화면 둘 다 육안 검수한다.

기존 11개 자동 검사는 리소스 로드·캐시·저장·앵커 존재를 검사하는 기능 검사다. 미적 품질이나 올바른 착용을 증명하지 않는다. 이전 V14 문서의 ‘연결 완료’는 시각 품질 합격으로 해석하면 안 된다.
