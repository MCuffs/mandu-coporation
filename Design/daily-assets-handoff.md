# 오늘의 도전조 에셋 적용 요청

원본은 Assets/DadSchoolBoss/Art 아래 ThrowHudV2, ThrowUiV2, ThrowHomeV1에 있다. 합성 효과음은 ThrowAudioV1에 있다. 각 폴더의 manifest.json에서 파일 이름과 규격을 확인할 수 있다.

1. 규칙 12종을 카드 하단에 104px, 전투 HUD에 30px로 표시한다. 카드 ID 앞에 rule_를 붙여 그림을 찾는다.
2. 도전장에는 paper_note와 rule_card_frame을 각각 96px, 48px 모서리를 고정해 늘린다. rule_chip은 좌우 40px을 고정한다. 이름과 금액은 게임에서 그린다.
3. 보상 세 줄에 나무·양철·금색 상자를 차례대로 매핑하고 이미 지급된 줄에는 열린 그림과 체크를 표시한다. 남은 기회와 사용한 기회는 chance_on/off로 표시한다.
4. 안개는 길 오른쪽에 fog_veil을 깔고 puff 세 장을 천천히 이동시킨다. 상자 동전 효과는 세 프레임을 같은 기준점에서 재생한다.
5. DI 소리 여섯 개를 봉투 열기, 도장, 상자 열기, 카드 배분, 기회 사용, 성공 이벤트에 연결한다.
6. 카드 뒤집기와 회색 신발 위 금지 표시의 사용 여부는 요청서 6절 결정을 따른다. 연결 후 dailyaudit으로 실제 화면 크기에서 확인한다.

검수용 규칙 아이콘 비교는 [미리보기](daily-rule-icons-preview.png)에 있다. 이번 납품은 원본 제작까지이며 게임 연결과 실기기 재생 검수는 후속 작업이다.
