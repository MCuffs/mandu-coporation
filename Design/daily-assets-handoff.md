# 오늘의 도전조 에셋 적용 요청

원본은 Assets/DadSchoolBoss/Art 아래 ThrowHudV2, ThrowUiV2, ThrowHomeV1에 있다. 합성 효과음은 ThrowAudioV1에 있다. 각 폴더의 manifest.json에서 파일 이름과 규격을 확인할 수 있다.

1. 규칙 12종을 카드 하단에 104px, 전투 HUD에 30px로 표시한다. 카드 ID 앞에 rule_를 붙여 그림을 찾는다.
2. 도전장에는 paper_note와 rule_card_frame을 각각 96px, 48px 모서리를 고정해 늘린다. rule_chip은 좌우 40px을 고정한다. 이름과 금액은 게임에서 그린다.
3. 보상 세 줄에 나무·양철·금색 상자를 차례대로 매핑하고 이미 지급된 줄에는 열린 그림과 체크를 표시한다. 남은 기회와 사용한 기회는 chance_on/off로 표시한다.
4. 안개는 길 오른쪽에 fog_veil을 깔고 puff 세 장을 천천히 이동시킨다. 상자 동전 효과는 세 프레임을 같은 기준점에서 재생한다.
5. DI 소리 여섯 개를 봉투 열기, 도장, 상자 열기, 카드 배분, 기회 사용, 성공 이벤트에 연결한다.
6. 카드 뒤집기와 회색 신발 위 금지 표시의 사용 여부는 요청서 6절 결정을 따른다. 연결 후 dailyaudit으로 실제 화면 크기에서 확인한다.

검수용 규칙 아이콘 비교는 [미리보기](daily-rule-icons-preview.png)에 있다. 이번 납품은 원본 제작까지이며 게임 연결과 실기기 재생 검수는 후속 작업이다.

## 적용 결과 (2026-11-18 밤, 사용자 "이거 보고 에셋 적용해주세요")

위 여섯 가지를 게임에 연결했다. 창 없는 검사 516개 통과, Unity 2021.3.2f1 에디터 1920×1080에서 컴파일·실행 오류 0, [화면 11장](dad-throw-daily-captures-2026-11-18/)을 다시 찍어 확인했다.

| 요청 | 한 것 |
| --- | --- |
| 1. 규칙 12종 | 도전장 카드 아래쪽에 104, 싸움 화면 위쪽 띠 아래에 30으로 나온다. 카드 이름으로 그림을 찾는다(`DadThrowDaily.IconKey`) |
| 2. 종이·카드 틀·표시 판 | 귀퉁이를 그대로 두고 늘려 그린다. 종이는 내용 칸보다 조금 크게 깔았다(제목이 종이 위쪽 가장자리와 테이프에 걸려서) |
| 3. 보상 세 줄, 기회 | 나무·양철·금색 상자를 차례로 붙였다. 받은 줄은 열린 상자와 체크. 기회는 손바닥. 줄마다 과제 그림도 왼쪽에 붙였다 |
| 4. 안개, 동전 | 세로 띠 16개를 걷어 내고 `fog_veil` 한 장과 천천히 흐르는 뭉치 셋으로 바꿨다. 결과 카드에서 닿은 보상의 상자가 차례로 열리며 동전이 튄다 |
| 5. 소리 여섯 | 봉투(도전장을 열 때), 카드(한 장씩 놓일 때), 도장(기회를 다 쓴 도전장), 기회 사용(도전을 누를 때), 성공, 상자(열릴 때마다). **이 게임에 처음 들어간 소리다.** 소리 끄기 설정은 아직 없다 |
| 6. 결정이 필요했던 것 | 「공만」의 신발 버튼은 회색으로 남기고 금지 표시를 얹었다(PM 추천안. 사용자 확답은 받지 않았다). 카드 뒤집기 연출은 넣지 않았다(`rule_card_back` 미사용) |

- 게임이 읽는 사본은 `Tools/install_daily_runtime.py`가 만든다: 그림 39장 → `Resources/DadThrowDailyV1/`, 소리 6종 → `Resources/DadThrowAudioV1/`.
- 쓰지 않은 그림 3장: `rule_card_back`(뒤집기 연출), `envelope_closed`(집 앞 화면의 우편함), `unlock_daily`(새 화면이 열릴 때의 알림. 알림 자체가 아직 없다).
- 화면을 보고 고친 것: 종이 크기(위 2번), 금지 표시가 "신발" 글자를 가려서 신발 그림 위로 옮김, 상자에서 튀는 동전이 "도전 성공!"을 가려서 작게.
- **확인하지 못한 것:** 소리를 귀로 들어 보지 않았다(재생 코드가 오류 없이 돈 것만 확인). 1280×720, 길쭉한 폰 화면, Android 실기기. 사람이 해 본 기록.
- **그림에 대한 PM 의견:** 열두 아이콘은 30px에서도 서로 구분된다. 다만 선이 가늘고 평평해서 인물 그림(굵은 만화 선)과 화풍 차이가 있다. 쓸 수는 있고, 승인 여부는 사용자가 화면을 보고 정한다.
