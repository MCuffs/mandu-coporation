# UI 방향 v9 — 피곤한 아빠, 과한 전투력

> 시나리오·제목 변경: 현재 기준은 [아빠 전쟁 v10](dad-war-scenario-v10.md)이다. 이 문서의 이전 출동 동기와 상대 설정은 최신 설정으로 간주하지 않는다.

2026-11-04. 사용자의 병맛 콘셉트 재확인에 따른 디자인 재구성. 일반적인 정돈된 복도 로비안은 채택하지 않는다. 이 문서와 HTML은 적용 전 디자인 제안이다.

## 기획 해석

기준은 초기 v1보다 이후의 `dad-redesign-v4.md`, `dad-structure-v5.md`와 현재 구현이다. 초기에는 각도 판단 중심 3분 로그라이트였으나 이후에는 짧은 스테이지, 아빠 키우기, 도시락 개봉으로 방향이 바뀌었다.

- 주인공: 도시락 배달하러 온 피곤하고 구부정한 아빠. 벗겨진 이마·수염·배·무표정이 정체성이다.
- 사건: 학교를 점거한 상대도 졸업 못 한 성인 아저씨들이다. 멋진 청소년 격투물이 아니다.
- 쾌감: 평범한 생활인처럼 보이는 아빠가 사람을 벽과 사물함으로 날려 연쇄를 만든다.
- 반복: 짧은 전투 → 코인/도시락 → 생활용품 장비와 강화 → 더 황당한 상대.
- 콘텐츠: 복도/급식실/체육관, 껌/쟁반/의자/피구 적, 42세 학교 짱·52세 급식실 실세·51세 체육 선생님(기획 설정).

현재 구현에는 6부위×3등급 장비, 4종 강화, 도시락 개봉·비교·장착·분해, 방치 보상이 있다. v5의 5개 탭, 상점/지도/광고 계획 전체가 구현된 것은 아니다. 새 시안에는 실제 있는 기능만 배치한다. 아래 전투 기록과 재화 수치는 시안용 예시다.

## 한 장면으로 설명하는 방향

**아빠는 지쳐 서 있는데, 옆의 아저씨는 사물함에 박혀 있다. 아빠는 “도시락만 주고 간다니까.”라고 한다.**

웃음은 ‘아빠의 태연함’과 ‘주변의 과한 결과’에서 나온다. 아빠를 멋있게 포즈 잡게 하거나 인테리어를 아름답게 만드는 방향보다 이 대비를 먼저 만든다. 계속 폭발시키기보다 대기 중의 정적과 짧은 과장 동작을 대비한다.

홈의 배경은 이야기의 결과가 남은 장소다. 찌그러진 사물함 1개, 떨어진 슬리퍼 같은 큰 단서만 쓰고 사방에 균열·파편·낙서를 채우지 않는다. 바닥과 UI 뒤는 단순하게 유지한다. 적을 보여줄 경우 명확한 성인 얼굴과 안전한 만화 표현을 유지한다.

## 화면 구성

### 홈: 출발 직전의 작은 코미디

- 상단 재화 → 압축한 게임 제목/전투력 → 아빠와 사건 흔적 → 방치 보상 → 현재 스테이지/출발 → 도시락·출발·강화 탐색 순서.
- 큰 제목으로 면적을 채우는 대신 가운데 장면이 게임의 정체성을 설명한다.
- 대사는 `도시락만 주고 간다니까.` 같은 짧은 일상 문장 1개. 음성·자동 넘김을 필수로 만들지 않는다.
- 방치 보상은 `엄마가 챙겨 놨다` + 실제 재화 + `받기`. 아빠 얼굴을 가리지 않는 별도 줄.
- 전투력 부족 상태는 정확한 수치와 강화 진입으로 안내한다. 웃긴 카피가 실패 이유를 대신하지 않는다.

### 도시락: 밥 대신 전투 장비가 나옴

- 가운데 아빠, 양옆 실제 6개 슬롯, 아래 큰 도시락과 열기 버튼.
- 장비의 유머는 효자손·리모컨·런닝셔츠 같은 생활용품을 엄숙하게 취급하는 데 있다. 판타지 장비처럼 미화하지 않는다.
- 개봉 카드는 물건이 주인공. 등급 → 물건 → 현재/신규 수치 → 장착/분해 순서.
- `엄마가 뭘 넣었지?`는 제목에 사용 가능. 행동 버튼은 `도시락 열기`, `장착`, `분해`로 유지한다.
- 확률과 등급은 현재 실제 3등급 체계를 표시한다. 기획서의 5등급 계획을 UI에 미리 표시하지 않는다.

### 강화: 생활 체력 단련

- 주먹·체력·연타·날리기를 기존 아이콘과 독립된 4행으로 보여준다.
- 이름/Lv/실제 변화/코인 비용/강화 버튼을 분리한다.
- 코믹한 보조 문구 예: 주먹 `주먹 쥘 일은 없었으면 했다`. 실제 효과 설명은 별도 표기.
- 현재 구현의 공통 전투력 증가와 개별 전투 보정은 코드를 확인해 정확하게 적는다. 아직 분리되지 않은 효과의 구체 수치를 만들어 보여주지 않는다.

### 전투: 과장된 결과를 읽게 만들기

- 홈과 같은 장식 밀도를 적용하지 않는다. 적·벽·돌진 방향이 먼저 보인다.
- 기본 타격 글자는 작게, 벽꿍과 큰 연쇄는 크고 짧게. 화면 모든 곳에서 같은 크기로 외치지 않는다.
- 필살기에는 아빠 얼굴/폴더폰 등 실제 장비별 소품을 쓴다. 충전 상태와 사용 가능 상태를 구분한다.
- 보스는 이름과 나이 설정으로 등장 농담을 전달하고, 전투 중에는 체력과 그로기 정보를 우선한다.

### 결과: 오늘의 처리 실적

- 복도 `복도 정리 끝!`, 급식실 `급식실 정리 끝!` 등 장소에 맞춘 짧은 제목.
- 아빠의 태연한 표정 + 작게 날아가는 성인 상대 + `처리 완료` 도장.
- 최대 연쇄/벽꿍/제압, 실제 코인/도시락, 다음 출발 순서.
- 실패는 `아빠도 가끔은 진다`와 보스 남은 체력/추천 성장. 모욕적인 대사보다 재시도 이유를 준다.
- 수리비 청구서 콘셉트는 새 소비 재화를 연상시키므로 채택하지 않는다.

## 시각 체계

- 인물: 현재 v5의 못생기고 웃긴 얼굴, 불균형한 성인 체격, 굵은 불규칙 외곽선, 단색 면/그림자 1단계.
- UI: 따뜻한 생활용품색, 짙은 먹색 외곽선, 짧은 한 단 그림자. 버튼마다 테마 소품을 그려 넣지 않는다.
- 색: 학교 녹색은 틀과 보조 상태, 노랑은 출발/개봉, 붉은색은 도장/주의, 등급색은 장비 테두리에 쓴다. 등급은 색 외에 명칭도 표시한다.
- 제목체는 로고와 짧은 코믹 강조에 제한. 숫자·설명·가격은 읽기 쉬운 한글 본문체. 기존 Black Han Sans와 Gothic A1의 용도를 분리해 먼저 검증하고, 교체가 필요하면 한글 범위/상업 사용 라이선스/실기기 렌더링을 확인한 뒤 확정한다.
- 투박함은 표정·형태·말투로 표현한다. 글자 뭉개짐과 잘림은 품질 문제로 고친다.

## 제작 에셋과 재사용

| 항목 | 재사용/제작 | 조건 |
|---|---|---|
| 아빠/생활 장비/재화/탭 | 기존 v5 재사용 | 캐릭터 얼굴과 실루엣 유지 |
| 개봉/장비 카드 | 기존 v6 우선 | 레이아웃에 맞는지 실제 배치 검증 |
| 홈용 사건 장면 | 신규 제작 후보 | 기존 그림으로 구성 검증 후, 찌그러진 사물함+성인 상대를 별도 레이어로 제작 |
| 아빠 무표정 얼굴/짧은 반응 | 기존 프레임 우선 | 새 얼굴로 교체하지 않음 |
| 도장/말풍선/버튼/카드 | 코드 또는 벡터로 제작 | 문자는 런타임, 크기 변경 대응 |
| 예쁜 빈 복도 배경 | 이번 방향에서 제외 | 기획의 압도감과 황당한 사건이 드러나지 않음 |

홈 사건 장면은 장식용 연출 제안이며 새로운 전투나 홈 보상 시스템이 아니다. 확정되기 전에 런타임 Resources에 새 배경을 연결하지 않는다.

## 시안과 다음 적용 기준

`dad-ui-concept-v9.html`에 기존 게임 PNG와 실제 글꼴을 사용한 홈·도시락·결과 3면 시안을 구성했다. 캐릭터는 별도 레이어이고 CSS 배경/도형은 배치 검토용이다. 사물함 충돌 장면은 아직 최종 일러스트가 아니다. 클릭/실제 저장/게임 진행은 구현하지 않은 정적 시안이다.

우선 이 화면 구조에 맞춰 필요한 홈 장면 레이어만 제작하고, Unity에서 폰트 선명도와 레이아웃을 검증한다. 그다음 장비·강화·전투·결과의 공통 컴포넌트를 연결한다. 신규 게임플레이·상점·광고 기능 확장은 이번 UI 작업과 별도다.
