# 아빠가 학교 짱을 너무 잘 잡음 — 플레이 초안 v2

2026-11-04. Unity 2021.3.2f1.

> 이후 밸런스·보스 그로기 작업은 [dad-prototype-v3.md](dad-prototype-v3.md)에 있다. 아래 장비 설명과 검사 수는 v2 시점 기준이다.

## 실행

`Assets/DadSchoolBoss.unity`를 열고 Play를 누른다.
메뉴 `Dad School Boss > Open Prototype`으로도 열 수 있다.
씬을 재생성해야 할 때만 `Prepare Prototype Scene`을 사용한다. 이 메뉴는 학교 씬을 새로 저장한다.

## 구현한 흐름

타이틀 → 장비 선택 → 1층 복도 전투 → 기술 3택 1 → 학교 짱 → 결과 → 재도전/장비 변경.

- 화면: 세로 540×960 기준, 실제 화면의 safeArea에 맞춰 배치.
- 이동: 터치/마우스 드래그, PC WASD/방향키.
- 공격: 가까운 적 자동 펀치. 위치로 넉백 방향을 바꾸고 벽·다른 적과 충돌시킨다.
- 필살기: 충전 100에서 하단 버튼/스페이스. 주변 적 넉백과 일시적 폭주.
- 성장: 레벨업마다 효과를 명시한 기술 3개 중 1개 선택. 선택 중 전투 정지.
- 적: 기본 접근형과 의자 돌진형, 돌진·광폭화를 사용하는 보스. 쟁반 캐릭터는 현재 기본 접근형의 외형 변형이며 정면 방어는 미구현.
- 목표: 일반 적 12명 제압 후 등장하는 보스 격파. 180초 안에 끝내지 못하면 패배.
- 장비: 고무 슬리퍼는 시작 벽 충돌 피해 +1. 튼튼한 도시락은 시작 충돌 전달 강화.
- 도시락 해금: 최고 3연쇄 또는 첫 승리. 최고 연쇄·승리 횟수·장비 선택은 별도 `DadV2.*` PlayerPrefs로 저장.
- 정지/복귀: 상단 정지 버튼, Escape, 포커스 상실 시 일시정지.

## 에셋

Codex 내장 image_gen으로 만든 새 아빠 4포즈, 적 4종, 복도 배경을 사용한다.

| 파일 | 내용 |
| --- | --- |
| `Assets/DadSchoolBoss/Resources/DadV2/Hero.png` | 대기·걷기·펀치·반동 |
| `Assets/DadSchoolBoss/Resources/DadV2/Enemies.png` | 껌 캐릭터·의자 돌진형·쟁반형·보스 |
| `Assets/DadSchoolBoss/Resources/DadV2/Arena.png` | 중앙이 비어 있는 학교 복도 |

생성물의 포즈 간 폭이 달라 균등 셀 분할은 사용하지 않는다. 초기 로딩 시 알파로 연결된 큰 실루엣 4개를 추출하고 원래 비율·상대 크기·발 기준을 보존한다. 겹치는 바운딩 박스 때문에 옆 캐릭터 일부가 들어오는 것도 분리한다. 이 전처리는 현재 초안에서 런타임에 1회 수행하므로, 모바일 출시 전에는 에디터에서 구운 스프라이트로 바꾸는 것이 적절하다.

모든 텍스트와 버튼은 Unity에서 그린다. 이미지에 생성된 글자를 사용하지 않는다. 기존 v1 아트와 기존 Alley 씬은 보존한다.

최종 프롬프트: [dad-assets-v2-prompts.md](dad-assets-v2-prompts.md).

## 구현 위치

- `Assets/DadSchoolBoss/DadSchoolPrototype.cs`: 전용 화면, 입력, 스프라이트 분리, 전투 어댑터, 기록 저장.
- `Assets/DadSchoolBoss/Editor/DadPrototypeSetup.cs`: 리소스 임포트, 씬 구성, 검사 메뉴.
- 기존 `AlleyCombat`의 이동·넉백·충돌·기술·보스 시뮬레이션을 재사용한다.
- 기존 자동 씬 열기 코드에는 학교 씬 작업 중 이전 Alley 씬으로 돌아가지 않도록 조건 1개를 추가했다.

## 검증과 남은 작업

기본 검사 10개와 Play Mode 통합 검사 11개가 통과했다. 기본 검사는 에셋 로드·실제 알파·슬리퍼 벽 피해·기술 선택·보스 승리·패배를 확인한다. Play Mode 검사는 실제 컴포넌트의 시작·이동·필살기·선택·기록 저장·장비·재도전을 확인한다. 각각 `dad-prototype-checks.txt`, `dad-prototype-playchecks.txt`에 결과를 기록한다. 통합 검사가 사용한 저장 값은 검사 전 상태로 복원한다.

에디터 화면에서 새 타이틀과 출발 버튼을 통한 전투 진입을 직접 확인했다. 이는 모바일 성능이나 재미·유지율 검증을 대신하지 않는다.

남은 범위: 적 공격/피격 전용 프레임, 쟁반 정면 방어, 사물함 파손, 타격 자세 연결 보완, 실기기 터치·글자 크기·성능 확인, 전투 밸런스 플레이테스트. 현재 장비·UI는 기능 검증용 초안이다.

현재 설치된 Unity에는 Android Build Support가 없어 APK는 만들지 않았다. 에디터에서 플레이할 수 있는 세로형 초안이다.
