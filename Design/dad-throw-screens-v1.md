# 아빠 전쟁 — 시작·정산·재도전·일시정지 화면 v1

2026-11-17. 가로1280×720 디자인 시안과 화면 전환 미리보기. 기존 가로 투척 게임의 단순한 흐름을 유지한다. 이번에는 Unity 런타임 코드를 변경하지 않았으며 이 화면은 기존 APK에서 나오지 않는다.

## 산출물

- 개별1280×720 화면: [시작](dad-throw-screens-v1/title.png), [웨이브 완료](dad-throw-screens-v1/clear.png), [실패](dad-throw-screens-v1/retry.png), [일시정지](dad-throw-screens-v1/pause.png).

## 화면과 전환

| 화면 | 표시 | 버튼·전환 | 의도 |
|---|---|---|---|
| 시작 | 기존 가로 원화 위 live 제목 ‘아빠 전쟁’ | 게임 시작→전투 배치 미리보기, 설정→소리/닫기 | 시작 행동 하나를 가장 크게 표시 |
| 웨이브 완료 | 팔짱 낀 아빠, 완료 제목, 코인+36 예시 | 강화30→보유6/버튼 비활성, 다음→전투 배치 | 장비·별·여러 보상 카드 없이 다음 판으로 연결 |
| 실패 | 땀 닦는 아빠, 짧은 문구, 웨이브3 예시 | 다시 도전→전투 배치 | 긴 실패 설명과 상품 제안 대신 재시도 |
| 일시정지 | 전투 배경을 어둡게 하고 작은 중앙 종이 패널 | 계속하기→전투 배치, 소리 토글, 나가기→시작 | 전투와 분리된 최소 설정 |

코인·웨이브는 디자인 예시 값이다. 미리보기 강화 버튼의 값 변경은 HTML 내부 시연이며 실제 게임의 재화·저장에 영향을 주지 않는다. 소리 버튼도 표시 토글만 한다. 타이틀 시작 버튼이 연결되는 전투 배치 화면에는 ‘전투는 실행되지 않습니다’를 명시했다.

완료/실패/정지는 별도 전체 배경을 생성하지 않고 기존 전장 위에 어둡게 덮는 오버레이로 디자인했다. 코드 연결 때는 실제 플레이 마지막 장면 위에 표시한다. 제목·문구·수치·버튼은 이미지에 굽지 않고 Black Han Sans/Gothic A1로 렌더링했다. 종이 패널·버튼은 HTML/CSS로 그려 글자 여백·색·버튼 상태를 수정할 수 있게 했다.

## 신규 에셋

- `dad_clear.png`: 팔짱 끼고 만족한 아빠.
- `dad_retry.png`: 쪼그려 앉아 땀을 닦는 아빠. 실제 생성물에는 작은 수건이 있으며 디자인에 채택했다.

내장 imagegen으로 기존 `DadThrowV1/dad_ready.png`를 인물/그림체 참조해 생성했다. 원본은 `Assets/DadSchoolBoss/Art/ThrowScreensV1/`, 리소스 준비 복사본은 `Assets/DadSchoolBoss/Resources/DadThrowScreensV1/`. 원본 프롬프트는 Art의 `prompts.json`, 이미지 크기·alpha 경계는 Resources의 `manifest.json`에 저장했다.

외부 투명 RGBA, 전체 인물/샌들 잘림 없음. Bilinear/Clamp, mipmap 없음, NPOT 변환 없음, 무압축, 최대2048 설정을 .meta에 기록했다. 기존 시작 원화와 전투 배경은 `DadThrowV1`을 참조하고 중복 생성하지 않았다.

## 검증과 후속

- 두 신규 원화의 투명 여백·파일 복사·잘림 없음 확인. 각 생성 이미지와 최종4면 비교를 직접 열어 외형과 문구 배치를 확인했다.
- Chrome headless로4개 화면과 비교 페이지를 오프스크린 렌더했다. Unity 캡처·Android 검수가 아니다.
- 실제1280×720 화면 PNG, HTML의 로컬 리소스 경로, 이미지 원본/복사본 일치, .meta 확인. `git diff --check` 통과.
- Unity/플레이어 창 실행, 코드 적용, APK 생성, 커밋·푸시는 하지 않았다. 기존 V20와 원본 프로젝트를 건드리지 않았다.
- 다음 적용 때는 시작/전투/완료/실패/정지 상태에 연결하고, 저장 여부에 따른 ‘계속하기’, 소리 설정 저장, 안전영역·실제 터치 타깃·기기별 글자 크기를 검수한다. 이 시안만으로 해당 기능이 구현됐다고 간주하지 않는다.
