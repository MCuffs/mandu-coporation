확정 사항: Google Play(Android), D1 리텐션30%, 사업자는 개인사업자, Play Console 미가입, D-U-N-S와 사업자 웹사이트 없음. 운영자 파랑버섯 스튜디오, 문의 alstnwjd0424@naver.com.

## 계정 준비 순서

내부 테스트는 선택사항이다. ‘12명·14일 연속 비공개 테스트’는 신규 개인 개발자 계정의 프로덕션 접근 요건이다. 정상적인 조직 계정 등록은 다른 경로지만 사업자등록증만으로 자동 승인되지는 않는다. 개인사업자의 등록 가능 여부는 실제 사업자 정보·D-U-N-S와 Google 인증으로 확인한다. [Google 테스트 요건](https://support.google.com/googleplay/android-developer/answer/14151465), [계정 유형](https://support.google.com/googleplay/android-developer/answer/13634885?hl=ko)

1. 사업자등록증의 정확한 상호·주소 기준으로 D-U-N-S가 이미 있는지 조회한다. 없다면 Google이 안내하는 무료 신청 경로를 사용한다. 신규 발급은 최대30일이 걸릴 수 있다.
2. 실제 사업자 웹사이트와 연락처를 준비하고 조직 웹사이트 인증을 진행할 수 있게 한다. 공개 처리방침 페이지가 사업자 웹사이트 인증을 자동으로 대신하는 것은 아니다. Google은 조직 연락처와 공개 개발자 이메일에 일반·개인 이메일 대신 조직에 연결된 공식 주소를 요구한다. 현재 네이버 주소는 게임 문의용으로 유지하되 조직 가입용 주소는 별도 준비한다.
3. D-U-N-S·Google 결제 프로필의 이름/주소를 일치시키고 조직 계정 등록·본인/사업자·이메일/전화 인증을 진행한다.
4. 앱 생성 후 AAB·서명·스토어 설명/이미지·등급·대상 연령·광고 포함 여부·Data safety·개인정보 링크를 실제 구현에 맞춰 제출한다.

가입·서류·D-U-N-S 발급과 심사 완료일을 보장할 수 없다. [Google 조직 정보 요구사항](https://support.google.com/googleplay/android-developer/answer/13628312?hl=ko), [신원/웹사이트 인증](https://support.google.com/googleplay/android-developer/answer/10841920?hl=ko)

## D1 30%의 의미와 검증

- 기준 시간대: 한국 시간. D0에 처음 실행한 신규 사용자 중 D1 날짜에 다시 유효 플레이한 비율을 본다. 같은 날 재실행은 D1이 아니다.
- 계산: D1 재방문 신규 사용자 수 / 해당 D0 코호트의 신규 사용자 수. QA·개발자·재설치 중복은 구분한다.
- 개발 가설: 첫 화면에서 바로 한 판, 첫 제압 후 돌진 선택, 12개 수제 배치, 별36개, 매일 바뀌는4판, 즉시 재도전이 돌아올 이유를 만든다.
- Windows 자동 검사·봇 승률은 Android D1 측정이 아니다. 현재 실제 D1 데이터와 설치 사용자 코호트는 없다.
- 내부20~50명은 조작 이해·자발적 재도전·다음날 방문 이유를 관찰하는 탐색 단계다. Android 소프트런칭에서100명 이상 성숙 코호트부터 수치와 표본 불확실성을 함께 검토한다. 이는 내부 검증 계획이며 효과 보장이 아니다.

## 광고 원칙과 실제 적용 상태

본편 첫3판에는 광고 제안을 만들지 않는다. 4판 이후 승리 결과의 코인 추가 보상만 선택형으로 준비했다. 광고 미선택이 다음 판을 막지 않는다. 배너·강제 전면 광고·패배 직후 강요·광고 시청에 따른 숨은 난이도 조절은 추가하지 않는다.

보상은 provider의 earned-reward 콜백에만 연결한다. 닫힘·취소·로드 실패에는 지급하지 않는다. 중복 콜백·중복 요청·이미 소비된 영수증을 거절하고, 완료 후30초 대기·세션5회 상한을 둔다. 재시작 후 이미 소비한 영수증이 다시 지급되지 않도록 저장한다. 서버 검증은 아직 없다.

**Windows v0.3 배포본에는 실제 광고가 없다.** 이후 `codex/dad-war-admob-test` 브랜치에서 Google Mobile Ads·UMP와 Android 공식 테스트 ID를 연결하고 실제 SDK에 대한 Android 스크립트 컴파일을 확인했다. Android 빌드·실기기 광고/동의 검증·AdMob 계정과 상용 ID·수익 설정·Data safety 제출은 미완료다. Windows의 `--dad-ad-demo`는 ‘실제 광고 아님’을 표시하는 수동 흐름 테스트다. [현재 광고 연결 상태](dad-admob-test-integration.md), [Google 보상형 광고 가이드](https://developers.google.com/admob/unity/rewarded)
