# 아빠 전쟁 — 시제품 B: 아빠가 직접 날아간다 (v1)

작성: 2026-11-04, PM. 사용자 결정(11/4): 자동 펀치 대신 **앵그리버드식으로 아빠를 당겨 쏘고, 그동안 상대 아빠들이 점점 다가오는** 방식으로 간다. 탄환은 우리 아빠 자신이다(몬스터 스트라이크형). 이 문서는 시제품의 규칙·수치·검증 결과다. 본 게임(`Assets/DadSchoolBoss.unity`)은 바꾸지 않았다.

## 1. 해 보는 법

1. Unity 메뉴 `Dad School Boss > Slingshot B > Open Prototype`(`Assets/DadSlingshot.unity`)을 열고 Play를 누른다.
2. 판 목록에서 B-1(연습)부터 B-보스까지 고른다.
3. 화면 아무 데나 누르고 **뒤로 당겼다 놓으면** 아빠가 반대쪽으로 날아간다. 당긴 길이가 세기다.

## 2. 규칙

| 항목 | 규칙 |
| --- | --- |
| 발사 | 당긴 방향의 반대로 날아감. 24px 미만은 취소, 150px에서 최대 속도 |
| 조준 | 첫 번째 벽 튕김까지 점선 예측(상대와 부딪히는 건 보여 주지 않음). 조준 중에는 다가오는 아빠들이 0.5배로 느려짐 |
| 비행 | 사물함·벽에 튕김(속도 88% 유지), 서서히 멈춘 자리에서 다음 발사. 날아가는 동안은 맞지 않음 |
| 들이받기 | 맞은 아빠는 아빠 진행 방향으로 날아가고(피해 1) 우리 아빠는 80% 속도로 계속 감. 한 번 쏠 때 같은 아빠는 한 번만 맞음 |
| 벽꿍 | 날아간 아빠가 벽·사물함에 부딪히면 피해 2, 사물함이 찌그러짐 |
| 연쇄 | 날아간 아빠가 다른 아빠를 맞히면 그 아빠도 날아감(피해 1). 한 발에 생긴 들이받기·연쇄·벽꿍을 모두 세어 "N연쇄!!" |
| 지호 아빠(접근형) | 문에서 걸어 내려와 닿으면 0.4초 준비 후 공격(8) |
| 의자 아빠(돌진) | 가까워지면 0.9초 예고선 뒤 돌진(14). 돌진 전에 먼저 날려야 함 |
| 쟁반 아빠 | 쟁반이 아빠가 서 있던 쪽을 막음. 정면으로 쏘면 튕겨 나옴(두 번이면 쟁반 박살). 벽에 한 번 튕겨 옆이나 뒤로 들어가야 함 |
| 학부모회장(보스) | 우리 아빠가 직접 들이받으면 튕겨 나옴(피해 1). **날아간 아빠를 맞히면 그로기 2.6초**, 그때 들이받으면 멀리 날아가 벽꿍(피해 3). 서 있는 동안 3.2초마다 아빠 한 명씩 추가 등장(탄약 역할), 체력 절반에서 광폭화 |
| 별 3개 | 클리어 · 체력 절반 이상 · 발사 횟수가 목표 이하 |

목표 발사 수: B-1 3번, B-2 4번, B-3 8번, 보스 12번.

## 4. 검증 결과

**규칙 검사 20개 통과**([dad-slingshot-checks.txt](dad-slingshot-checks.txt)). Unity 에디터 안과 밖에서 같은 결과다.

**자동 플레이 봇**([dad-slingshot-bot.txt](dad-slingshot-bot.txt), 판마다 60번). 봇은 가장 가까운 아빠를 노리는 단순한 규칙이라 사람의 재미나 실력을 대신하지 않는다. 판이 끝까지 깨지는지와 길이·압박을 가늠하는 용도다.

| 판 | 초보 봇(오차 20°, 조준 1.5~2.5초) | 숙련 봇(오차 5°) |
| --- | --- | --- |
| B-1 | 승리 60/60, 7초, 체력 100 | 승리 60/60, 6초 |
| B-2 | 승리 60/60, 11초, 체력 92 | 승리 60/60, 8초 |
| B-3 | 승리 60/60, 23초, 체력 80 | 승리 60/60, 18초 |
| 보스 | **승리 52/60**, 37초, 체력 40 | 승리 60/60, 35초 |

첫 조정 전에는 조준 슬로 0.3배 때문에 어떤 봇도 한 번도 맞지 않았다. "다가오는 압박"이 사라진 상태라서, 조준 슬로 0.5배·걷기 속도 1.4배·공격 준비 0.4초로 조정했다.

## 5. 사람 테스트에서 볼 것

1. **손맛:** 직접 만든 연쇄·벽꿍을 설명하는가(v2 기준 20명 중 12명).
2. **압박:** 다가오는 아빠가 긴장으로 느껴지는가, 조급함으로 느껴지는가. 조준 슬로 배율(0.3~0.7)을 바꿔 가며 비교한다.
3. **조작:** 화면 아무 데나 당기기 vs 아빠를 직접 잡아 당기기 중 무엇이 더 자연스러운가.
4. **보스:** "졸개를 날려 그로기 → 들이받기" 순서를 안내 문구 없이 알아내는가.
5. **반복:** 별 3개(발사 수)를 노려 다시 하는가.

## 6. 알려진 한계와 다음 일

- 연쇄 배지가 위쪽 문 근처의 상대를 가린다. 다음 수정에서 화면 가운데 아래로 옮긴다.
- 날아가는 아빠는 `special` 그림 한 장을 회전시킨 것이다. 이 방식이 채택되면 날아가는 자세·착지·벽 튕김 그림이 필요하다(로드맵 1단계 에셋).
- 장비가 탄환 성질을 바꾸는 규칙(슬리퍼 = 더 튕김 등), 2·3층 공간 규칙(급식 카트·반발 매트), 광고 지점은 아직 넣지 않았다.
- 모바일 실기기 터치는 확인하지 않았다(에디터 마우스 기준).
