## 판단과 범위

현재 약점은 장비 그림만이 아니다. 화면의 정보 위계, 실패에서 배우는 피드백, 새 상대의 대응법, 앱 전환·일시정지·저장 복구가 빠져 있었다. 장기 반복 재미나 유저 잔존은 실제 플레이어 관찰 자료가 없어 판단하지 않는다. 이번 구현은 기존 슬링샷의 조준·벽 튕김·연쇄를 이해하고 반복할 수 있게 만드는 작업이다.

## 검증 결과와 한계

**관찰한 사실**

- 런타임/에디터 C# 컴파일 성공. 기존 Alley 미사용 필드 경고 3개.
- Unity 검사 210개 통과: 이번 14, 기존 연결 50, 경제/리소스 73, 장비 14, 난이도/저장 59.
- Unity 1080×1920에서 타이틀·시나리오 자막·홈·지도·장비·강화·조준·비행·정지·설정·승리·실패·새 상대 안내를 촬영하고 육안 확인했다. 임시 진행 데이터를 사용했고 끝나면 원래 진행 데이터와 전역 기록을 복원했다.
- macOS Development 앱 빌드 성공, 오류/경고 0. 약 489MiB인 개발 빌드이며 Android 설치 크기를 의미하지 않는다.
- Apple M1에서 실제 앱을 실행해 7개 검사 통과: 메인 씬, 독립 저장, 한글 폰트, 조준, 정지 중 시뮬레이션 불변, 재개 후 1발만 발사, 홈/정지 실제 렌더링. 실행 로그에 예외 없음, 종료 코드 0.
- 실행 검사는 `--dad-smoke-root <임시 경로>`를 사용해 사용자의 원래 저장 파일을 쓰지 않는다. 조준/발사는 프로그램으로 호출한 기능 검사이며 실제 손가락이나 마우스 제스처 검사를 대신하지 않는다. 네이티브 자동 검사는 포커스와 무관하게 진행되도록 개발 테스트에서만 백그라운드 실행한다.

**아직 증명하지 않은 것**

- Android에서의 터치 조작, 진동, 프레임 시간, 발열, 메모리와 백그라운드 복귀.
- 유저가 안내를 이해하고 실패 후 스스로 재도전하는지, 반복 재미·D1 잔존·매출.
- 모든 장비 조합과 60판 전체의 수작업 밸런스 검수.
- 제품 UI는 아직 IMGUI 기반이며, 복잡한 화면 전환·접근성·다양한 기기 검증을 포함한 출시 UI 검수를 마친 것은 아니다.

## Android 출시 차단 항목

사전 점검 스크립트 `python3 Tools/check_dad_android_release.py`의 결과는 **BLOCKED**다. 설정 점검만으로 AAB 적합성을 인증하지 않는다.

1. 현재 Unity **2021.3.2f1**은 16KB 지원 패치보다 오래됐다. Unity 공식 안내는 2022.3.56f1+, 6000.0.38f1+, 6000.1+ 등을 지원 버전으로 명시한다. 2021.3.48f1+는 Enterprise/Industry 연장 지원 항목이다. [Unity 공식 안내](https://discussions.unity.com/t/android-unity-engine-support-for-16-kb-memory-page-sizes-android-15/1589588)
2. 이 컴퓨터의 해당 에디터에는 Android Build Support가 없다. 현재 빌드는 macOS 검수용이다.
3. 프로젝트 Android 아키텍처 값이 ARMv7 단독이다. ARM64를 포함한 실제 Android 빌드·네이티브 라이브러리 검증이 필요하다.
4. Target SDK는 Automatic이며 실제 API 36 빌드를 확인하지 않았다. 2026-08-31 이후 신규/업데이트 제출은 일반 Android 앱 기준 API 36 이상이 필요하다. [Google 공식 기준](https://developer.android.com/google/play/requirements/target-sdk)

다음 기술 작업은 지원 중인 Unity 6 LTS로 **별도 사본에서** 업그레이드하고, Android SDK/NDK/JDK 및 ARM64 AAB를 구성해 실제 산출물을 검증하는 것이다. 버전 문자열이나 SDK 숫자만 바꿔 통과한 것으로 표시하면 안 된다. 현재 작업 사본은 엔진 버전을 바꾸지 않았다.

## 다음 제품 관문

1. Android 엔진·빌드 환경 정비 후 저사양/중간급 실기기에서 첫 10판과 중단·복귀·저장 검수. 앱 크기·리소스 메모리도 측정한다.
2. 타깃 성인 플레이어 5명에게 설명 없이 10분 제공한다. 아래는 업계 평균이 아니라 초기 가설 판정 기준이다: 4명 이상이 15초 안에 첫 발사, 3명 이상이 쟁반 대응을 자기 말로 설명, 3명 이상이 첫 실패 후 요청 없이 재도전. 실패한 항목을 먼저 고친다.
3. 첫 10판에서 빗나감·이동 대기·강화 필요성·압도적 공략을 관찰한 뒤 전투 간격과 레벨 배치를 조정한다. 그림이나 기능 수로 재미를 판단하지 않는다.
4. 그 후 2·3층의 규칙 차이와 보스 연출, 장기 콘텐츠를 검수하고 광고·결제 및 스토어 자료를 결정한다.

현재 판정: 화면과 앱 동작은 검증된 개선이 있으나, **상업성은 테스트 가능한 가설 단계**다. 스토어 출시 판단은 Android 산출물과 실제 플레이어 증거 뒤에 한다.
