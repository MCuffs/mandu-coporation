# 아빠가 학교 짱을 너무 잘 잡음 — 플레이 초안 v3 (한 판 밸런스 · 쟁반 짱)

2026-11-04. Unity 2021.3.2f1. v2([dad-prototype-v2.md](dad-prototype-v2.md))에 이어지는 작업이다.

## 배경

v2 마지막 상태에서 자동 조작 완주 결과는 `43초 승리, 체력 100`이었다. 보스가 40초에 나와 3~5초 만에 쓰러졌고, 피해를 거의 받지 않았다. 기획서([dad-school-boss-v1.md](dad-school-boss-v1.md))의 목표와 비교하면 다음이 어긋났다.

| 항목 | 기획 목표 | v2 결과 | v3 현재 |
| --- | --- | --- | --- |
| 한 판 길이 | 150~240초 | 약 45초 | 약 115~135초 |
| 한 판 기술 선택 | 3회 (2~4회) | 4회 | 3회 (일부 4회) |
| 보스 | 일반 공격으로는 짧게만 밀리고, 다른 적이나 환경 충돌로 그로기 | 일반 펀치·폭주로 바로 녹음 | 졸개를 던져 그로기 → 벽꿍 |
| 쟁반 짱 | 정면 넉백을 줄이고 측면 충돌에 약함 | 외형만 있음 | 정면 방어·느린 방향 전환·측면 박살 |

## 변경

모든 규칙은 학교 모드 전용 옵션이다. 기존 Alley 모드의 기본값과 회귀 검사는 그대로다.

### 폭주·필살기

- 폭주 2.4초, 필살기 충전 획득량 0.55배. v2 마지막 패치를 검증했다.

### 판 구조 (`SchoolRunDirector`)

1. 교육 (0~24초): 펀치 → 벽꿍 → 연쇄 순서 학습, 동시 최대 3명.
2. 혼합 웨이브: 24~60초 최대 5명, 60초 이후 최대 6명. 돌진형 비중이 늘어난다. 36초부터 쟁반 짱이 나온다.
3. 보스: 제압 55명 이후 100초가 지나면 등장한다. 늦어도 135초에는 나온다.

레벨 곡선은 4배다. 첫 선택은 12명 제압, 이후 28·48명에서 나온다. 한 판 선택은 대부분 3회다.

1차 조정(쟁반 짱 이전)에서는 제압 45명·80초·배율 3이었다. 적이 2종뿐이라 판을 더 늘리지 않았고, 쟁반 짱을 넣은 뒤 지금 값으로 늘렸다.

### 보스 그로기 규칙

| 상황 | 결과 |
| --- | --- |
| 그로기 전 일반 펀치 | 피해 0, 조금 밀림. 폭주 중에도 날아가지 않음 |
| 그로기 전 강타 | 피해 1 (칩 피해) |
| 졸개가 날아와 부딪힘 | 그로기 1.8초(+기절 기술), 피해 2+연쇄 기술 |
| 그로기 중 펀치 | 피해 +1, 날릴 수 있음 (넉백 0.75배) |
| 그로기 중 벽 충돌 | `짱 벽꿍!!` 피해 2+벽 기술, 그로기 종료 |
| 폴더폰 필살기 | 보스 겁먹음, 그로기 1.4초 |

보스 체력은 28이다. 등장할 때 졸개 2명이 함께 나오고, 이후 4.5초마다 최대 3명까지 보급된다. 졸개는 보스를 여는 탄환 역할이다.

### 쟁반 짱

쟁반 짱은 기본 접근형에 쟁반 규칙을 더한 적이다. 체력 4, 이동 속도 0.85배. 36초 이후 웨이브 3번에 1번 등장하고, 동시에 최대 2명까지 나온다.

| 상황 | 결과 |
| --- | --- |
| 정면 펀치 (쟁반 쪽 좌우 60° 안) | `쟁반 막기!` 피해 0, 조금 밀림 |
| 정면으로 날아온 몸 | `팅!` 튕겨 나감, 연쇄 없음 |
| 위·아래·뒤에서 펀치 또는 날아온 몸 | `쟁반 박살!` 쟁반 제거, 피해 +1, 정상 넉백 |
| 정면 4번 | 쟁반이 찌그러져 깨짐 (돌아가지 않아도 결국 뚫림) |
| 필살기 (폭주·폴더폰) | 범위 안의 쟁반을 모두 깸 |
| 방향 전환 | 아빠가 반대편으로 넘어가도 0.55초 뒤에 돌아섬. 그 사이 뒤가 빔 |

쟁반은 스프라이트상 좌우만 향한다. 그래서 정면은 좌우 방향이고, 복도 위아래에서 치면 옆구리다.

정면 4번 규칙은 2차 조정에서 넣었다. 넣기 전에는 정면만 치는 초보형이 슬리퍼 3/8, 폴더폰 2/8로 크게 졌다. 돌아가는 법을 모르면 영원히 막히는 구조는 캐주얼에 맞지 않는다고 봤다.

처음 등장할 때 `쟁반 짱!  위아래나 뒤에서 때리세요` 배너를 띄운다. 쟁반 짱이 남아 있는 동안 힌트는 `쟁반은 정면만 막아요 · 위아래나 뒤에서!`다.

### 장비

- 폴더폰 해금 조건은 누적 벽꿍 15회에서 60회로 바꿨다. 판 길이가 늘어 한 판에 벽꿍이 30~60회 나오므로, 기존 조건으로는 첫 판에 모든 장비가 풀렸다. 지금은 약 두 판이 필요하다.
- 폴더폰 필살기에 `엄마 응원` 체력 +6을 붙였다. 폭주 무적이 없는 대신 버틸 힘을 준다.

### 화면

- 보스전에는 상단 제압 수 자리에 보스 체력바를 표시한다. 그로기 중에는 노란색으로 바뀌고 `그로기! 벽으로 날려라` 문구가 뜬다.
- 그로기 보스 머리 위에 별 3개가 돈다.
- 상단 힌트에 반투명 종이색 바탕을 깔았다. 보스가 복도 위쪽에 서 있을 때도 읽힌다.
- 쟁반 짱: 쟁반 앞쪽에 흰 테두리 선을 그린다. 돌아서는 중에는 노랗게 깜빡이고, 정면으로 막을 때마다 찌그러진 자국이 하나씩 생긴다. 깨진 쟁반에는 금이 간 자국을 그린다. 막기·튕김·박살에는 높은 금속음과 회색 파편이 나온다.
- 쟁반 외형(atlas 2번)은 쟁반 짱에만 쓴다. 기본 적은 껌 짱(0번)으로 통일했다.

### 버그 수정: 비스듬한 선이 제자리를 벗어남

`Line()`이 `GUIUtility.RotateAroundPivot`을 썼다. 이 함수는 기준점을 화면 좌표로 해석하므로, 화면 배율과 여백이 적용되면 가로가 아닌 선이 엉뚱한 곳에 그려졌다. 영향 범위는 돌진 예고선, 아레나 세로 경계선, 타격 파편, 공격 예고선이었다. 캡처 바깥 검은 여백에 흩어지던 선들이 이 버그였다. 지금은 `Sprite()`와 같이 현재 GUI 행렬 안에서 회전한다.

## 밸런스 프로브

`Dad School Boss > Run Balance Probe`로 실행한다. 결과는 [dad-balance-probe.txt](dad-balance-probe.txt)에 기록된다. 장비 3종마다 자동 플레이어 2종으로 시드 8개씩 돌린다.

- 숙련형: 돌진 예고를 옆으로 피한다. 쟁반 짱은 위아래로 돌아가서 친다. 필살기는 적 3명 이상이거나 보스전일 때 쓴다. 보스전에서는 졸개를 보스와 일직선에 세운다.
- 초보형: 가장 가까운 적에게 직진한다. 필살기가 차면 바로 쓰고, 기술은 무작위로 고른다.

폴더폰 초보형의 패배 5판은 모두 보스전에서 나왔다. 빨간 돌진 예고를 전혀 피하지 않는 봇이라, 폭주 무적이 없는 장비로는 보스 돌진(18 피해)을 계속 맞는다. 폴더폰은 두 판쯤 해야 풀리는 장비이고 숙련형은 8/8이므로 더 맞추지 않았다.

자동 플레이어는 규칙이 의도대로 작동하는지 보는 도구다. 사람의 재미나 실제 난이도를 대신하지 않는다.

## 에디터 원격 명령

Unity 에디터가 켜져 있으면 `Library/DadPrototypeCommand.txt`에 명령 한 줄을 쓴다. 에디터가 읽고 실행한 뒤 파일을 지운다. 완료되면 `Editor.log`에 `DAD_COMMAND_OK: <명령>`이 남는다.

파일은 임시 파일에 쓴 뒤 이름을 바꿔 한 번에 넣는다(`mv`). 그대로 쓰면 에디터가 빈 파일을 먼저 읽고 지울 수 있다. 에디터 쪽도 빈 파일이면 지우지 않고 다음 프레임에 다시 읽는다.

| 명령 | 내용 |
| --- | --- |
| `refresh` / `bake` | 에셋 새로고침(스크립트 재컴파일) / 스프라이트 굽기 + 새로고침 |
| `checks` · `polishchecks` · `flowcheck` · `balance` | 검사·시뮬레이션·밸런스 프로브 |
| `play` · `playchecks` · `stop` | Play Mode 진입, 통합 검사, 종료 |
| `pump` | 에디터가 백그라운드일 때도 Play Mode 화면을 계속 그림 (캡처용) |
| `start` · `home` · `capture:<경로>` · `status` | 판 시작, 홈, 화면 캡처, 상태 로그 |
| `skipboss` · `groggycapture:<경로>` | 디버그: 보스 단계로 건너뛰기, 보스 그로기 상태 캡처 |
| `spawntray` · `traycapture:<경로>` | 디버그: 쟁반 짱 2명과 돌진 준비 중인 의자 짱 소환, 45프레임 뒤 캡처 (`DAD_CAPTURED` 로그) |

## 남은 일

- 판 길이 115~135초. 기획 범위(150~240초)의 아래쪽보다 조금 짧다. 사람 플레이에서 지루함과 피로를 보고 정한다.
- 초보형의 보스전이 숙련형보다 짧다. 필살기를 자주 쓰고 강타 칩 피해가 쌓이기 때문이다. 사람 플레이로 확인이 필요하다.
- 쟁반 짱 전용 프레임(쟁반 없는 모습)이 없어, 깨진 뒤에도 쟁반을 든 그림에 금 간 자국만 그린다.
- 적 공격·피격 전용 프레임, 실기기 터치·글자 크기·성능 확인.
- 설치된 Unity에 Android Build Support가 없어 APK는 아직 만들 수 없다.
