## 연결 기준

- 현재 Unity 런타임에는 연결하지 않았다. 원화를 Resources에 복사하거나 기존 자산을 덮어쓰지 않는다.
- PNG 임포트 메타는 미리 준비했다. Clamp·mipmap 없음·최대 2048 기준이며 실제 Unity 임포트·실기기 검수는 후속 단계다.
- 투명 레이어는 바탕 사각형 없이 합성한다. 알파 밖의 RGB 값으로 검정 배경 유무를 판단하지 않는다.
- 효과 셀은 좌상단 기준 각 768×512다. 원점을 Unity UV로 바꿀 때 Y 방향을 뒤집고, 필터링 번짐을 막을 여백을 유지한다. 프레임을 반복 재생하는 애니메이션 시트가 아니라 서로 다른 효과 4종이다.
- SVG는 벡터 형태 기준이다. 현재 프로젝트에 SVG 런타임 패키지를 추가하지 않았다. 런타임 UI로 형태를 재현하거나 정해진 파이프라인으로 임포트한다.
- 텍스트·보상 수치·등급·버튼 라벨은 Unity에서 표시한다. 시안 숫자는 실제 저장값이 아니다.
- 홈 배경은 현재 2D 개선용이다. 유사 3D 캐릭터 모델·리그·3D 전투장의 납품이 아니다.
